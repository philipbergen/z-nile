# R0140: Input and look cores

## Theme
Single-issue feature raft delivering `f0203` (Input and look cores): four pure leaf Logic modules in `arcade/src/shared/Logic/` (`Rng`, `Pad`, `Touch`, `Look`) plus their rule documentation in `arcade/.tracker/architecture.md`.

Decisions relied on (quoted from `f0203`):
- `arcade/.tracker/architecture.md` (Technical skeleton): "Game Logic never requires arcade Logic. Arcade features are leaves that adapters wire in, and game Logic gets them as parameters (an RNG, a store, a travel status)."
- `arcade/skills/arcade-arch` rule 2: "Per-game differences are parameters, never a branch on a game's name."
- `pickman/.tracker/game-design.md`: every feature supports keyboard, gamepad and touch (`f0146`); default gamepad stick hysteresis 0.6/0.4 with 15° diagonal margin, 0.15 look dead zone, squared response, 3 rad/s yaw, 2 rad/s pitch; 48 px swipe / 30° cone / 44 pt touch target; 0.12 s quarter-turn easing (`f0104`).
- `snake/`, `invaders/`, `asteroids/` game designs: horizontal-only stick steering, held touch buttons, and eased/blended look.

## Whole-raft design
Single member (`f0203`):
- `arcade/src/shared/Logic/Rng/init.luau`: seeded Park-Miller generator (`Stream`, `Generator`, `Draw`, `new`, `int`, `float`, `draw`).
- `arcade/src/shared/Logic/Pad/init.luau`: generic gamepad folds (`tune`, `isPad`, `track`, `steerStart`, `steer` with `"both"` and `"horizontal"` axes, `look` in radians).
- `arcade/src/shared/Logic/Touch/init.luau`: generic touch fold (`empty`, `inside`, `zone`, `swipe`, `track`, `reset`, `toScreen`, `screenSize`).
- `arcade/src/shared/Logic/Look/init.luau`: free look, arrow spring-back, eased turn, and snapshot blending (`tune`, `wrap`, `approach`, `rate`, `ease`, `mouse`, `turn`, `snap`, `rest`, `arrows`, `press`, `quarters`, `spring`, `alpha`, `blend`, `blendYaw`).
- `arcade/tests/unit/{Rng,Pad,Touch,Look}/*.spec.luau`: unit specs for all four features.
- `arcade/.tracker/architecture.md`: adds `## Input and look cores (f0203)` before `## Allowed dependencies` (no new `deps` edges; all four are leaves).
