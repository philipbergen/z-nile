# R0143: Asteroids classic rules

## Theme
Feature raft delivering Asteroids' complete pure Logic rules: `f0220` (Asteroids classic rules) and `f0221` (Asteroids two players). Both share `asteroids/src/shared/Logic/Pilot`, `asteroids/src/shared/Logic/Classic`, and `asteroids/.tracker/architecture.md`, with `f0221` directly depending on `f0220`.

Decisions relied on (copied verbatim from `f0220` and `f0221`, quoting `asteroids/.tracker/game-design.md`):
- Pillar (2): "Deterministic Logic."
- The field and view: "The rules are 2-D: a flat, wrap-around field (leave one edge and you come back on the opposite edge), as in the arcade. Rocks tumble in 3-D for looks only."
- Rules: "**The ship** turns at a fixed rate and thrusts with inertia and slight drag, up to a top speed."
- Rules: "**Shots:** up to 4 on the field at a time, each lasting about 1 s, and shots wrap round the field too."
- Rules: "**Hyperspace** puts the ship at a random spot, with a 1 in 6 chance of exploding on re-entry (a tuning constant)."
- Rules: "**Rocks:** large splits into 2 medium, medium into 2 small, and small is destroyed. They score 20, 50 and 100. Ramming one costs a life (the rock still splits)."
- Rules: "**Waves:** wave 1 has 4 large rocks, and each later wave adds 2, up to 11. Clearing every rock starts the next wave after 2 s."
- Rules: "**Saucers:** the large saucer (200) fires at random. The small saucer (1,000) aims at you, gets more accurate as the score rises, and appears more often in later waves. They cross the field edge to edge."
- Rules: "**Lives:** 3, with one extra every 10,000 points. After a death the ship respawns at the centre once the centre is clear, protected for 2 s (shown by a flicker)."
- Rules: "**Game over:** the revive offer (1 R$ for 3 new lives, keeping score and wave)." (`f0220` freezes score, wave, and field at game over; `f0221` provides per-player `revive`; the offer/purchase is `f0223`.)
- Every game supports keyboard, gamepad and touch (`f0203`, pickman's rule `f0146`): Logic takes one `Input` value whatever the device.
- 2 players: "Both ships share one field, starting on opposite sides, with the same waves (the rock count is ×1.5)."
- 2 players: "Each has their own score, lives and revives, so it is a race for the most points on shared rocks."
- 2 players: "Default: shots pass through the other ship (no friendly fire), but ships bounce off each other. The user may change either."
- 2 players: "If one player is out with no revive, the other plays on alone."

## Whole-raft design
Shared modules and public interfaces between `f0220` and `f0221`:
- `asteroids/src/shared/Logic/Field`, `Ship`, `Rocks`, `Saucers` (created by `f0220`, untouched by `f0221`).
- `asteroids/src/shared/Logic/Pilot` (created by `f0220`, extended backwards-compatibly by `f0221`):
  - `f0220` exports:
    ```lua
    export type State = "alive" | "hyperspace" | "dead"
    export type Cause = "rock" | "saucer" | "saucershot" | "hyperspace"
    export type Shot = { x: number, y: number, vx: number, vy: number, life: number }
    export type Controls = { turn: number, thrust: boolean, fire: boolean, hyperspace: boolean }
    export type Config = { field: Field.Field, ship: Ship.Config, lives: number, extraLifeEvery: number, shotLimit: number,
    	shotSpeed: number, shotLife: number, hyperspaceTicks: number, hyperspaceOdds: number, respawnTicks: number, protectTicks: number }
    export type Pilot = { ship: Ship.Ship, shipState: State, timer: number, protect: number, shots: { Shot },
    	lives: number, score: number, nextExtra: number }
    export type Event = { kind: string, lives: number?, cause: Cause?, x: number?, y: number? }
    export type Draw = (n: number) -> number
    function Pilot.new(c: Config, x: number, y: number): Pilot
    function Pilot.controls(input: any): Controls
    function Pilot.exposed(p: Pilot): boolean
    function Pilot.award(p: Pilot, c: Config, points: number, emit: (Event) -> ())
    function Pilot.lose(p: Pilot, c: Config, cause: Cause, emit: (Event) -> ()): boolean
    function Pilot.clock(p: Pilot, c: Config, draw: Draw, clear: () -> boolean, emit: (Event) -> ()): boolean
    function Pilot.control(p: Pilot, c: Config, controls: Controls, draw: Draw, emit: (Event) -> ())
    ```
  - `f0221` adds:
    ```lua
    export type Home = { x: number, y: number }
    export type Cause = "rock" | "saucer" | "saucershot" | "hyperspace" | "shot"
    export type Pilot = { ..., home: Home? } -- nil defaults to field centre
    function Pilot.home(p: Pilot, c: Config): (number, number)
    ```
- `asteroids/src/shared/Logic/Classic` (created by `f0220`, run-wide step helpers exposed by `f0221`):
  - `f0220` exports `Phase`, `ShipState`, `Cause`, `By`, `Shot`, `Input`, `Event`, `Config`, `Game`, `Classic.TICK_RATE`, `Classic.CONFIG`, `Classic.new(seed: number, config: Config?): Game`, `Classic.step(g: Game, input: Input?): { Event }`, `Classic.rockCount(c: Config, wave: number): number`.
  - `f0221` adds `Home`, `Rock`, `Saucer`, `Player`, `Run`, extends `Event` with `player: number?, shooter: number?`, and exposes:
    ```lua
    function Classic.draw(g: Run): Rocks.Draw
    function Classic.seed(seed: number): number
    function Classic.spawnWave(g: Run, ships: { Ship.Ship })
    function Classic.clearAt(g: Run, x: number, y: number): boolean
    function Classic.clock(g: Run, p: Player, events: { Event }): boolean
    function Classic.control(g: Run, p: Player, input: Input?, events: { Event })
    function Classic.moveRocks(g: Run)
    function Classic.saucerStep(g: Run, target: Player?, events: { Event })
    function Classic.moveShots(g: Run, p: Player, foe: Player?, events: { Event })
    function Classic.moveSaucerShots(g: Run, players: { Player }, events: { Event })
    function Classic.collide(g: Run, p: Player, events: { Event })
    function Classic.waveClock(g: Run, ships: { Ship.Ship }, events: { Event })
    ```
- `asteroids/src/shared/Logic/TwoPlayer` (created by `f0221`): composes `Classic` and two `Pilot` tables on one field.
- Agreement: `f0220`'s `Classic.Game` structurally satisfies `f0221`'s narrower `Classic.Run` and `Classic.Player` supertypes (with `f0221` passing `{ g }` as `{ Player }` in `Classic.step` to satisfy Luau array invariance), and both designs agree on `Pilot`, `Event`, and `Cause`.
- `asteroids/.tracker/architecture.md` (touched by both): already declares all seven Logic features (`Field`, `Ship`, `Rocks`, `Saucers`, `Pilot`, `Classic`, `TwoPlayer`) and all 13 acyclic `deps` edges (`TwoPlayer -> Classic`, `TwoPlayer -> Field`, `TwoPlayer -> Ship` atop `f0220`'s edges).
