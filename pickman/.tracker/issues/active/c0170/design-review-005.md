## Candidate lessons (for the lead)
- zz-arch (note on guards-decide-from-the-tools-resolution): on a case-insensitive filesystem the resolver's name for a file may differ from the listing's; a guard that compares paths canonicalizes them against the real listing, or fails closed on a name the listing doesn't hold. - zz-test or z-design: a placement rule that judges only the folders it names lets the thing it governs move to a folder nobody judges. Check: where else could the governed file live and still pass, and does the rule state the converse (who may load it), not only where it may not be? (F2)
