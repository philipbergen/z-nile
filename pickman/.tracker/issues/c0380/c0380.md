# c0380: Narrow board pins for revives

## Problem
- f0186 (Boards show revives, user's decision of 2026-10-31 in f0186's Problem) changes text that eight promoted cases pin today under `pickman/tests/acceptance/`: d0124/lobby.spec (3 cases), d0124/adapters.spec (1), f0026/adapters.spec (3), f0026/endtoend.spec (1) and f0026/lobby.spec (1), as named in the rough idea.
- f0186 also changes text that five cases of f0145's specs pin: lives.spec (1), top.spec (1, its `Lobby.lines` assertion), views.spec (2) and place.spec (1, its phrase list). These are sequestered in `pickman/.tracker/issues/f0145/acceptance/` today and move to `pickman/tests/acceptance/f0145/` when f0145 is done.
- All thirteen cases are red on the f0186 prototype. That prototype is the uncommitted working tree of `.worktree/proto-f0186-on-f0145`, on commit e396d79b6 (the same commit as `proto-f0145`). The run was the full pickman gate plus f0145's sequestered specs, on 2026-11-15.
- `proto-f0186` (f0186 on main without f0145) is not the reference for this chore. It can only show the eight d0124/f0026 cases.

## Non-goals
- No file under `pickman/src/` changes, and neither does `game-design.md`.
- The new text ("REVIVES n", the struck-through 5 R$ on sale for 1 R$) is pinned by f0186's own acceptance specs, not here.
- `pickman/tests/unit/Lobby/boards.spec`, which f0186 turns red, is f0186's to update.
- f0145's sequestered specs are not edited before f0145 is done. If f0145 is still open when this chore is designed, the narrowing of its five cases waits for the promotion.

## Solution
- This chore starts only after f0145 is done (`depends_on: [f0145]`), so its baseline is main with f0145 landed and f0145's specs promoted to `pickman/tests/acceptance/f0145/`.
- On that baseline, each of the thirteen cases is narrowed in place and still passes there, with no change under `pickman/src/`.
- With f0186's prototype changes from `.worktree/proto-f0186-on-f0145` applied to the same baseline, every case in `pickman/tests/acceptance/d0124/`, `f0026/` and `f0145/` passes.
- Each narrowed row line still pins its mark, rank, name, score and level, and the rows' order and count, and allows any text after the level.
- Each narrowed best line still pins "YOUR BEST <score> <level>" as its start.
- The narrowed buy lines still pin their free, held, closed and test-note parts and the minutes to the next free game, and no longer pin "1 ROBUX A GAME".
- The f0145 cases that pin stored lives are unchanged. Only the two display pins (`Lobby.livesText`/`Lobby.LIVES_MARK` in lives.spec, and the `Lobby.lines` assertion in top.spec) and the "lives spent" phrase in place.spec's list are removed.
- f0186 gains `depends_on` c0380.
