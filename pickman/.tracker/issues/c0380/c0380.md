**The cut.** Each narrowed file that compares board text gets one local helper, word for word the same in all seven (`acceptance/narrowed.spec` pins that text):
```lua
-- c0380: what follows the level changes (f0145's lives, then f0186's revives), so a board's lines are pinned up to
-- the level: each line of `text` that is the line `want` has there, or starts with it and a space, is cut back to it;
-- every other line, and the number of lines, stay as they are, so a compare with `want` still shows them.
local function upToLevel(text: any, want: string): any
```
`t.expect(upToLevel(x, W)).toBe(W)` passes exactly when `x` has `W`'s lines, as many and in order, each either equal to `W`'s line or that line, a space and anything. So a row still pins its mark, rank, name, score and level (a level `3` does not match `30` or `3.0`), the rows' order and count, and allows any text after the level (the Solution's row rule); a best line pins "YOUR BEST <score> <level>" as its start. A non-string (nil) is returned as it is, so a missing line fails on the assertion.
