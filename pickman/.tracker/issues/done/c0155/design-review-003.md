### F1 [medium] The "off by a pixel" variants move each field only up (+1), so a case that pins each rectangle with an upper bound only passes AC1 (third hole in the same perturbation mechanism: review 001 F1, review 002 F1)
Where: `acceptance/narrowed.spec.luau` `nudged` (`out[field] += 1`) and the case "f0110's case walks at least today's 13 screens …"; Design, "must fail when `snap`, `fire` or `hop` has any one of `x`, `y`, `w`, `h` off by one pixel".
Evidence: X1, in the clone: f0110's `t.expect(b.fire).toEqual(T.fireRect(box))` replaced by `local fr = T.fireRect(box)` / `t.expect(b.fire ~= nil and b.fire.x <= fr.x and b.fire.y <= fr.y and b.fire.w <= fr.w and b.fire.h <= fr.h).toBe(true)`; `lune run tests/run -- .tracker/issues/c0155/acceptance/narrowed.spec.luau`: `5 passed, 0 failed, 1 spec files`. The case no longer pins `fire`: a fire button one pixel left, or one pixel smaller, passes it.
Critique: each round has found one more predicate the perturbation lets through (all samples at once, a call count, now one direction). The tempting fix is a `-1` variant beside `+1`. That one does close it: a case that rejects both neighbours of every field on every call is, for integers, exact for all practical predicates (only `x ~= v-1 and x ~= v+1`-style checks survive, which no one writes). But questioning the mechanism: the other way to "prove the case pins the value" is to hand the case a value that differs from the right one by *any* amount and in *any* direction; ±1 is the smallest and cheapest representative, so keeping perturbation with both signs is the fix that holds.
Consequences: 13 × 3 × 9 = 351 runs instead of 195, still about 1–2 s in every gate after `done` (measured 1.0 s for today's 195). A `-1` on `w` or `h` of a 44 px+ rectangle stays positive, so no variant builds a degenerate rectangle that would raise a non-assertion error. Error labels need the sign (`call k: fire.x -1 still passed`).
Recommendation: in the spec (it is a rule about f0110's case, which must hold in every gate after `done`, so a spec case, not a check.sh AC): `nudged(r, field, by)` and loop `by` over `{ 1, -1 }`; rename the case to say "off by a pixel either way"; reword the Design sentence and the Test plan line to match. Add a Rules row and mutant M14 (`fire` checked with `<=` on all four fields, X1 above) to `mutants.py`, run it and record it killed.
Lesson: zz-test/refusals-tested-on-both-sides
