# R0101: Narrow ramp pins

## Theme
c0176 (Narrow shipped config level pins, size 35) and c0177 (Narrow f0125 speed pins for ramp, size 90): two chores that narrow promoted specs so they stay true once f0147 (R0094) puts a level ramp in `Session.GAME_CONFIG`. Both change only files under `pickman/tests/acceptance`, and neither changes anything in `pickman/src/`. They are f0147's last two unmet dependencies (`depends_on: [f0126, f0125, c0176, c0177]`), so this raft is what stands between R0094 and its start.
Shared surface: the promoted specs that build sessions or measure speeds with the shipped config. c0176 changes `f0023/session-ghosts`, `f0100/drops`, `f0100/shots`, `f0101/airborne` and `c0153/golden`; c0177 changes `f0125/speeds`. No file is changed by both.
User decisions the designs rely on, copied from `pickman/.tracker/game-design.md`:
- c0176: "**Levels** (the classic rules, kept for the default config the specs use; the shipped game follows *Levels by picked walls*, f0147)". Its four specs keep pinning those classic rules, through the shipped config less its ramp.
- c0177: "Ghosts run at **1 / 1.1** of the classic hunting, tunnel and frightened speeds, never changing the eyes, through `Session.GAME_CONFIG.ghostTuning` (f0125). (On the shipped ramp, f0147, that is 1 / 1.1 of the ramped speeds: the same config without the tuning, c0177.)". Its spec keeps measuring that factor, now against the same config without the tuning.

## Whole-raft design
The two members share an idea, not an interface: each replaces "the shipped config" in a promoted spec with a local copy that names what the case is really about.
- **c0176**: `local CLASSIC_GAME = table.clone(Session.GAME_CONFIG) :: any` with `CLASSIC_GAME.ramp = nil`, passed to the eight `Session.new` calls of four specs, so they keep pinning the classic level 1 and the last pellet's clear. `c0153/golden.spec.luau` pins `f0100/drops.spec.luau` by digest, so that one value moves with it.
- **c0177**: `f0125/speeds.spec.luau` gains `untunedOf` (a clone with `ghostTuning = nil`), `classicOf` (a clone with `ramp = nil`) and `levelsOf` (`ramp.top` or `Levels.COUNT`), and measures the 10% against `untunedOf(GAME_CONFIG)`. It reads `ramp` and `Levels.ghostRate` loosely (`:: any`, with a fallback to `Levels.ghostSpeed`), so the file passes on today's main and on f0147's prototype.
The two clones do not meet: c0176's four specs never read `ghostTuning`, and c0177's spec builds its own. Each member pins its changed files whole (SHA-256 of the exact text, item ids masked) in its own `acceptance/narrowed.spec.luau`, over disjoint files, so neither member's pin reads a file the other changes.
No change to `pickman/.tracker/architecture.md`. Two things c0177's design changes outside its patch landed with its prep (#358), so execution does not make them: the one sentence added to game-design.md's Slower-ghosts row, and the reworded AC1 and AC3 labels of `pickman/.tracker/issues/done/f0125/check.sh` (the commands are unchanged; c0177's `narrowed.spec` reads that file for its run lines).

## Exit criteria
`./zn done R0101` succeeds: RC0, which is pickman's gate (`--project pickman --affected`), both members' check.sh files and `promote-check R0101`. RC1 is the one raft-level check: the branch changes nothing of the game (`git diff --quiet origin/main...HEAD` over pickman's `src`, `default.project.json`, `lobby.project.json`, `scripts` and `.tracker/architecture.md`), which is the claim the Theme and the rollback rest on and which no member can check for the other.

## Risks & rollback
- **A base moved.** Each member's pin is a digest taken in prep. If main changes one of the six files before the raft starts, the member's step 1 stops and the member goes back to z-design for a new pin; the executor never edits a sequestered pin.
- **f0147 lands a different ramp shape.** c0177's loose reads were run against f0147's prototype as designed on 2026-11-14. If f0147 is redesigned, its own Override check owns the difference.
- **An emergent issue needs a game file.** RC1 then fails, on purpose: this raft is specs only. Stop and escalate; the fix belongs to its own item.
- **Rollback**: revert the raft's commit. Only spec files change, so nothing in the game moves.
