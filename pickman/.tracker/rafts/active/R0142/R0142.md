# R0142: Walls built once per maze

## Theme
Single-issue chore raft delivering `c0228` (Walls built once per maze): eliminates the redundant wall rebuild on a maze's first frame by passing marks to `MazeView.build` and skipping redundant redraws in `MazeView.rewall` via `View.runsKey`, with zero player-visible behavior change.

Decisions relied on (quoted from `c0228`):
- `pickman/.tracker/game-design.md`: marked walls stay gold (including while walls are green); level-clear flash lights all walls white; picks open interior walls only.

## Whole-raft design
Single member (`c0228`):
- `pickman/src/shared/Logic/View/init.luau`: adds `View.runsKey(rects: { Rect }): string` comparing wall runs by value.
- `pickman/src/client/MazeView.luau`: `MazeView.build(m, marked?)` accepts optional marks; local `walls()` tracks drawn `runsKey` per model in a weak-keyed table and skips redraw when unchanged.
- `pickman/src/client/Main.client.luau`: builds the maze with `View.frameMaze(frame)` and `marked`, keeping the first-frame `MazeView.rewall` call (now a no-op) so promoted specs stay green.
