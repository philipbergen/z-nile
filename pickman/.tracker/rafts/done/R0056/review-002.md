The tempting fix is to teach the selector about `fs.readFile` literals.
Consequences: changing the selector is z-nile's tooling (zz-arch, its own issue and raft), and widens every source-reading spec's selection; reading Main through the built place instead keeps the selector as it is and makes this spec read the source that ships (the rojo-built Script), as f0109's place spec does.
