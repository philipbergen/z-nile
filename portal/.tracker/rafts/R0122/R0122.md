- **c0373** (draft) changes `deploy.yml`'s trigger; whichever lands second adapts.
- **The Beta deploy**: today's GitHub variables publish the same two places to the same ids (Regression guard); the new attributes read as today's absent ones. OC1 checks it on Beta after the PR is ready.
- **Rollback**: revert the merge; `pickman/scripts` and its alias come back, and the next deploy publishes as before.
