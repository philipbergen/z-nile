# R0141: Arena maps growth

## Theme
Single-issue feature raft delivering `f0211` (Arena, maps and growth): pure Logic rules for Snake's grid arena, non-connecting wall placement, movement with 2 buffered turns, apples and growth, collisions, lives, respawn, and map progression.

Decisions relied on (quoted from `f0211`):
- `snake/.tracker/game-design.md`: Solo arena 20×20; N-player side `ceil(sqrt(400 + 250*(N-1)))` (Formula wins: 47 for 8, 65 for 16, decided with user 2026-11-15); speed 4 tiles/s + 0.25/map capped at 7; Left/Right with 2 buffered turns; (players+1) apples, +1 length, 10×map points; map k has k−1 non-connecting straight walls (1 empty tile all round including diagonals, spawn areas clear, map 2 near middle), growing side by 2 if walls don't fit; goal length 10 + 2k with 2 s MAP CLEAR and 100×k bonus; 3 lives, 1.5 s death wait, 2 s Ready at farthest free tile.
- `arcade/.tracker/architecture.md`: game Logic never requires arcade Logic; randomness enters via local `Draw = (n: number) -> number`.
