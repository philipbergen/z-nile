# c0530: Acceptance spec typing

## Problem
`scripts/tracker.sh promote-check R0090` failed with 18 type errors in three sequestered acceptance specs, so `tracker.sh done R0090` would have rolled back: `f0170/flow.spec` (8) and `f0150/eating.spec` (9) pass mixed number/string array literals such as `{ 0, "ready" }`, which `luau-lsp analyze` rejects; `f0170/game.spec` (1) assigns to an undeclared `_`. A test-infrastructure defect, so a chore. It blocked the raft's `check.sh` and could not be postponed. The user approved editing the sequestered specs (2026-09-30, "fix and cont").

## Non-goals
<!-- Explicit scope fences. Anything tempting that belongs to another issue. -->

## Solution
Type-only edits, no behaviour change: the mixed rows are built with a local `row(...)` helper, and `_, ok =` becomes `events, ok =` (a variable already in scope). The code reviewer must expect these three files in the sequestration diff.
