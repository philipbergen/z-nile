# c0060: Affected changed files spec

## Problem
`scripts/affected.luau`'s `changedFiles` (git diff against the merge-base, the working tree, and untracked files) has no spec. R0010 added `--no-renames`, so that a file moved out of `src/` still selects place specs, but removing the flag would go unnoticed (R0010 review-002 F1).

## Non-goals
<!-- Explicit scope fences. Anything tempting that belongs to another issue. -->

## Solution
Add a tooling spec that builds a throwaway git repo in a temp dir, commits a file under `src/`, moves it out, and asserts that `lune run <root>/scripts/affected` (run with that repo as cwd) lists the old `src/` path's dependants, or asserts on an exported `changedFiles`.
