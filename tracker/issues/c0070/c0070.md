# c0070: Done ready before final push

## Problem
`tracker.sh done` pushes its final commit while the PR is still a draft, so CI skips it (`if: draft == false`). It then runs `gh pr ready`, and the ready-for-review run tested the *previous* head. R0010's final commit, the one that promotes acceptance specs into `tests/`, only got CI through a manual dispatch on 2026-09-29 (run 36519133807).

## Non-goals
- Changing the CI trigger policy for drafts.

## Solution
_Draft ideas; design happens in ticket-prep._
Mark the PR ready before pushing the done commit, or dispatch CI for the final head and wait for it (reuse `scripts/ci-verify.sh`). Pin this with a spec that asserts the ordering.
