# c0120: Move pickman into pickman/

## Problem
The game lives at the repo root beside the tooling, so a second game cannot sit beside it and a developer cannot tell the game from the tracker. The user (2026-10-20) wants each project to hold its own issues in its own `.tracker/`, and pickman's files moved into `pickman/`: its `src/`, its tests, its Rojo projects and places, and its tracker items into `pickman/.tracker/`.

Decided with the user (2026-10-20):
- The move raft is readied only when no raft is active. Prepped rafts move with the tree.

From the plan the user approved (2026-10-20): specs are promoted into the project they belong to, and each project has its own gate.

Decided with the user (2026-10-20), from the programme review:
- "Run checks from the project dir": `zn check` runs a pickman item's `check.sh` with the working directory at `pickman/`, so the paths sequestered files name still resolve. A spec asserts that every path each `check.sh` names exists. No sequestered file changes.
- "No active raft, no open branches": c0120 is readied only when no raft is active and no branch or worktree changes `tracker/`, `src/` or `tests/` (compact's busy-branch check). Afterwards a gate check fails if the old root reappears.
- R0030 (c0083) and R0039 (c0075) are re-prepped after c0120 lands.

## Non-goals
- Moving the tracker engine, skills and build into `z-nile/`, and z-nile's own issues: c0114.
- Renaming skills: c0115.

## Solution
- `git mv` the game and pickman's tracker items in one change, with history pathspecs that still see the old paths.
