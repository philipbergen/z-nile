# c0490: Beta poll transient errors

## Problem
`beta` is now a merge condition (R0080), and `OpenCloud.execute` raises on any non-200 while creating or polling a Luau Execution task, so one transient 429 or 5xx turns `beta` red and blocks the merge, with no retry and no documented recovery (R0080 review-001 F2).


## Non-goals
<!-- Explicit scope fences. Anything tempting that belongs to another issue. -->

## Solution
Retry 429 and 5xx (a few attempts with a pause, like the publish retry on 409) when creating and polling a task, with spec cases and a mutant per rule, and document in the tracker skill what to do when `beta` is red for a transient reason (rerun the job).
