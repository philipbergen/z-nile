# c0550: Board opens by default

## Problem
A developer running `scripts/tracker.sh board` almost always wants to look at the page, but today it only writes `.cache/board.html` and prints the path; the browser opens only with `--open`. `board` should open the page in the default browser by default, and `-O` should suppress that (write and print the path only).

## Non-goals
- Changing the board's content, layout or output path.
- Choosing a browser other than the system default.

## Solution
- In `cmd.board` (`scripts/tracker/main.luau`), open unless `-O` is given; keep the existing opener (`open` / `xdg-open`) and its warn-on-failure behaviour.
- Decide whether `--open` stays as an accepted no-op or is removed; update the usage line and the tracker skill's `board` row either way.
- `.github/workflows/board.yml` must pass `-O`, so CI never tries to launch a browser.
- Specs that run `board` should pass `-O` (or stub the opener) so the test run doesn't open pages.
