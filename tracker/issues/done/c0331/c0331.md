# c0331: PR-visible review cadence

## Problem
The skills treat the draft PR as a placeholder until `tracker.sh done`. Review starts, review findings and fixes are committed locally, and (per execute-raft Phase 4) only pushed as a side effect of later commits. A human watching the PR cannot see that a review is running, what it found, or whether it was addressed. Desired: the PR is a live record of the work.

## Non-goals
- Changing `tracker.sh` behavior (c0070 covers the done/ready ordering).
- Design-review of rafts on main (no PR exists yet).

## Solution
- execute-raft Phase 4: push before launching each reviewer and post a PR comment "Review NNN started at <sha>"; push once the reviewer's `review-NNN.md` is committed, with a PR comment summarizing findings by severity and verdict; push again after `refute-NNN.md` and fixes, with a comment answering each finding. Repeat per round.
- Phase 0-3: push after each commit (already done by `tracker.sh commit`), and post a short PR comment when an issue finishes.
- review skill: the reviewer's file is committed and pushed by the author's harness, never left local; add "Visible record" section.
- tracker skill: document the PR as the visible record and the cadence.
