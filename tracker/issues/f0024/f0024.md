# f0024: Hiscore store

## Problem
Scores need to persist across sessions on three boards: all-time top N, daily and weekly, the latter two keyed by UTC period.

## Non-goals
- UI (f0026). Anti-cheat beyond the server being authoritative.

## Solution
_Draft ideas; design happens in ticket-prep._
A pure `Hiscores` interface (submit, top(board, n)) with an in-memory fake for tests, and an OrderedDataStore adapter with retry, backoff and budget handling. Period keys are computed in Logic. It's validated on Beta via the c0003 smoke tests.
