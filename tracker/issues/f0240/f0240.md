# f0240: Hiscore submit

## Problem
At game over, the server has to submit the player's final score and level from its own simulation, never from the client. The boards update without double submissions.

## Non-goals
- UI (f0250).

## Solution
_Draft ideas; design happens in ticket-prep._
Game over triggers a single submission to all three boards, with display name and user ID, idempotent per game ID. Failures are logged and retried; they never block the player.
