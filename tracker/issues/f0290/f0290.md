# f0290: Pellet rendering

## Problem
f0150 and f0160 make pellets real in Logic, but nothing draws them. Without this the player can't see what's left to eat, can't find the power pellets, and nothing visibly happens when they eat one. The snapshot from f0120 carries only the player, so the client doesn't even know which pellets are gone.

## Non-goals
- Pellet rules and scoring (f0150, f0160). Score display (f0180). Sound. Art polish beyond a clear, readable look.

## Solution
_Draft ideas; design happens in ticket-prep._
- Extend the snapshot with pellet state for the owning client: a full set on join or level start, then per-tick "eaten" deltas, rather than the whole grid every tick.
- A client adapter that builds one part per pellet from the maze at build time and hides it when the delta arrives. Power pellets are larger and pulse, so they're visible down a long corridor.
- Placement rules (pellet height at eye level or on the floor, size relative to the tile) in a pure module so a place test can check them against the maze.
- On level start, every pellet reappears.
