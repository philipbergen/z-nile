New spec `launcher-lock.spec` (4 cases, AC3), Rules rows with mutants (launcher records nothing, wrong pid, through a link; all killed in the prototype), a live case reading the real lock under the Linux gate, and `c0058/lock.spec` stays in Regression guard as the proof. consequences: one more live pid in the lock on macOS (harmless, takeover rule unchanged); `c0079/watchdog.spec` drives `REAPER` with the variable unset (guarded in Regression guard); a lock left by a killed top is freed once the launcher is gone; the launcher's record is a write from the runner into `.cache` (reviewed: exclusive, no-follow, folder check).
