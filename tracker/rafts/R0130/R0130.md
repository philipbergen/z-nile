# R0130: Tracker hardening

## Theme
Five chores that close gaps in the tracker's own machinery, each found while executing R0010 to R0060 and each one a cost every raft pays or a trap the next raft can fall into:

- **c0070**: `tracker.sh done` pushes while the PR is a draft, so the final commit gets no CI (hit on R0010 and R0060).
- **c0360**: `done` has no honest answer for a medium or low review finding that is deferred, so agents must write `refuted: below the merge threshold`, which the check can't tell from a real refutation.
- **c0330**: a finished issue's `check.sh` stops working once its specs are promoted, so a done raft's criteria can't be re-run (six issue scripts and two raft scripts are broken today).
- **c0060**: `scripts/affected`'s changed-file list, including the `--no-renames` rule, has no spec.
- **c0050**: seven specs clone the real repository with hardlinked objects (the iCloud corruption of R0010), and `SETUP.md` doesn't warn about cloud-synced checkouts.

All five are tracker, test and CI tooling chores (the project's rule: tooling issues are chores, even when they are defects). **No product decision in `tracker/game-design.md` is involved.**

Closed during this prep, so they are not in the raft: c0331, c0340, c0350 and c0370 (delivered by R0020 and the skills) and c0080 (superseded: since c0420 the documented conflict procedure renumbers on your own branch before merging, so the other item with that number isn't in the tree). Each carries a `closed:` line saying why. There is no close command, so they were moved to `done/` by hand.

## Experiments phase
All run in prep, with results in each issue. In short:
- **c0070 E1-E3**: a GitHub-looking local origin plus a fake `gh` makes `done`'s order observable; the spec fails on the current code and passes with the designed order. A mutant (no rollback) survived until the fixture got a promotable acceptance spec.
- **c0360 E1-E2**: the designed grammar passes 9/9 on a scratch copy; five mutants die.
- **c0330 E1-E4**: the c0090 locator repairs six scripts (five pass fully; c0010's AC3 and AC5 are branch-bound by nature); designed `ac.sh` and template pass the spec 5/5; mutants die.
- **c0060 E1-E3**: the extracted module passes 9/9; five mutants die, one of which exposed a missing case.
- **c0050 E1-E3**: `--no-hardlinks` removes the sharing; the six call sites pass; mutants die.
Nothing is left for the executor's experiment phase except re-confirming that each spec fails on the unmodified code before implementing.

## Exit criteria
- **RC0** (generated): the full gate passes, every member issue's `check.sh` passes, and the acceptance specs survive promotion.
- **RC1**: every finished item's `check.sh` (issue or raft, not `closed:`) lists its checks with `AC_LIST=1` from an unrelated directory. This is the end-to-end proof that the tracker's history is re-runnable again.
- **RC2**: no skill still describes the interim deferral form or the old `done` order.
- "Done" is `scripts/tracker.sh done R0130` succeeding.

## Risks & rollback
- **A wrong `deferred` check could block a legitimate `done`** (or let a high finding through). Mitigated by the spec's seven cases and by `fixed`/`refuted` being untouched; rollback is reverting the `reviewProblem` hunk.
- **`gh pr ready` before the final push**: if the commit or push then fails (no network), the PR is ready with a stale head and the items are moved locally; the human re-runs `git push`. This window is seconds and replaces one of the same size (between push and ready) that existed before.
- **One extra CI run**: the `ready_for_review` event runs the gate on the previous head. Accepted (the trigger policy is out of scope).
- **`ac.sh` is sourced by every `check.sh`**: the list mode is inert unless `AC_LIST` is set; the spec runs the done scripts only after proving that `ac.sh` honours it (otherwise it refuses, to avoid running the whole gate recursively).
- **Six existing specs are edited by c0050** (call sites only). Each is run before and after; rollback is reverting that commit.
- **Rollback of the raft**: it is one PR; revert it.
