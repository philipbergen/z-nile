# R0028: Board graphs

## Theme
A single chore, **c0073**: the tracker board computes statistics about the work and draws them as graphs. The user asked for statistics on 2026-10-03, and on 2026-10-05: "Make a single issue raft that puts the graphs in the board"; asked whether that meant charts or moving c0073 out of R0025, they answered "both". c0073 was prepped inside R0025 through four design-review rounds (R0025's `design-review-00{6..9}.md`); it left R0025 in PR #62 and its design was widened here from tables to charts. Tooling: a chore.

User decisions relied on (quoted in c0073's Problem):
- views of a month by day, a quarter by week and a year by month;
- bucket edges rounded down to Monday, the 1st, the quarter start or Jan 1;
- per type: opened, closed and net, time, and lines (added, removed, net);
- defect % of (defects + features) and chore % of all, by count and by time;
- time in each state.

Prep decisions for the user to adjust: the window starts and the calendar periods (c0073, Usability), and the chart forms (c0073, Charts on the page).

## Whole-raft design
One issue. See c0073 Design:
- `stats.luau` (pure numbers);
- `history.luau` (git log, parsed purely);
- `chart.luau` (pure SVG);
- the board model and page (a Stats section beside the tabs, charts plus a Table toggle);
- `board.yml` full history.

No `src/` change, no `tracker/architecture.md` change.

## Risks & rollback
- **Page weight**: the real board is already about 1.5 MB, mostly embedded documents. The 67 SVGs add about 140 KB today (about 380 KB for a busy year). AC10 caps the Stats section at 450 KB on a generated busy year. If it exceeds that, render the bucket charts client-side from the embedded rows instead, which is a design change: escalate.
- **c0042's smoke harness** only stubs the old elements, so the page script must guard every new element (c0073 Design).
- **R0021's spec rules** apply (fixtures through `@tests/lib/fixture`, no banned names). c0073's specs were written to them.
- Rollback: revert the squash commit. The board then loses its Stats section; nothing else depends on it.
