# Design refute 001: R0150

- F1: fixed: f0300 `place.spec` gains "Camera no longer locks the mouse unconditionally", which forbids `MouseBehavior = Enum.MouseBehavior.LockCenter` directly and `MouseIconEnabled = false`. The design states the conditional lock line, and the new row F18 was run and killed. consequences: none beyond the row; the prototype's conditional line passes.
- F2: fixed: f0300 `adapter.spec` gains "the PlayAgain handler takes only the sending player…". It reads the `OnServerEvent` handler that calls `Session.playAgain`, requires exactly one parameter (optionally typed), and requires both the `[<param>]` session lookup and `tostring(<param>.UserId)`. Row F19 (a second, client-sent `Player`) was run and killed. consequences: it pins the handler shape to a `function(<p>)` literal inside `:Connect(...)`, which is the repo's adapter idiom; noted in the f0300 design.
- F3: fixed: f0290 `wire.spec` gains "slots returns a fresh list: changing it changes nothing" (mutating the list and an element, then checking a second call and `encode`). Row M20 (return the cached table) was run and killed. consequences: none.
- F4: fixed: f0180 `layout.spec`'s degenerate case adds `{ math.huge, 720 }` and `{ 1280, math.huge }`. The design states the guard `v > 0 and v < math.huge`, the AC is reworded, and row H14 was run and killed. consequences: none.
- F5: fixed: reworded rather than lowered. The rule is that the centre sits below the eye and the ball clears the floor and wall tops. A power pellet's top at 4.5 studs passing the 4-stud eye is intended, so it reads at distance. The case name, the AC3 text and the row are updated. consequences: none; the assertions were already exactly this.
- F6: fixed: the design (f0300, f0290, f0180 and the raft interfaces) states that every `start()` precedes `ready:FireServer()`, that per frame the order is Camera, HUD, overlay, then `PelletView.show` last, and that `lit` is reset on a maze rebuild. f0300 `place.spec` gains "Main starts every adapter before it signals Ready", and row F20 was run and killed. The decode order and the `lit` reset are adapter-internal and left to OC1. consequences: none.
