### F1 [medium] The `format` = `none` branch has no row and no case, and the edge case it covers is the next placeholder raft
Where: c0043 Design → `tracker.sh metrics`, the `none` bullet; Rules and mutants (no row for `none`; the issue-directory row is `reasoned` with no case); `acceptance/rounds.spec.luau`.
Evidence: Every raft in the repo today has a `design-review-001.md` (R0001–R0007), so no spec case ever sees a raft without one. But `tracker.sh prompt` creates placeholder rafts (`--single`, make-prompt step 1), and these have no design review. So this is the one input that will certainly show up. A wrong implementation that calls `fs.readFile(dir .. "/design-review-001.md")` unguarded, or labels a missing file `classic`, passes all five specs today. Once the first placeholder raft is committed, the first one crashes `tracker.sh metrics` (and the promoted `rounds.spec` with it, turning main red), and the second quietly adds a fake `classic` row to the baseline. By the new item 0's own rule, this is a missing row.
Critique: The table claims the metrics rules are pinned, but the branch that's certain to be hit next is the one left out. The tempting fix is a `reasoned` row that says "no such raft exists today", like the issue-directory row.
Consequences: A `reasoned` row records the gap but doesn't close it: the crash mutant still passes, and it would surface as a red main in someone else's raft. A real case needs a raft without reviews, and the live tree must not be mutated while the gate runs, since "every raft once" reads the same directories. The prototype shows a sandbox is cheap: copy `scripts/`, `.luaurc` and `rokit.toml` into a scratch directory with a hand-written `tracker/` tree, then run `bash <sandbox>/scripts/tracker.sh metrics`. No clone is needed, unlike the lifecycle spec. The cost is one more pin in a promoted spec: if `metrics` later needs git or files outside `scripts/`, the sandbox has to grow. The same fixture can also turn the `reasoned` issue-directory row into a `run` row, at no extra cost. Put a `design-review-001.md` in a fixture issue directory and assert that its raft still reads `0` design rounds.
Recommendation: Add a sandbox case to `rounds.spec`. Use `.cache/c0043-rounds` (wiped first, like `tracker-lifecycle`), with raft `R9990` having only its doc, and raft `R9980` having `design-review-001.md` without `Consequences:` plus a member issue directory that holds its own `design-review-001.md`. Expect `| R9990 | 0 | 0 | none |` and `| R9980 | 1 | 0 | classic |`. Add rows: "no design review → `none`" (mutants: unguarded read; missing → `classic`, `run`), and change the issue-directory row to point at this case, `run`. Say in Regression guard that the sandbox copies `scripts/`, `.luaurc` and `rokit.toml` only.
