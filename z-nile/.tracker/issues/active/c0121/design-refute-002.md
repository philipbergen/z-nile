# Refute 002: c0121 (answers to design-review-002)
The prototype `proto-c0121` is amended. The prep folder's `prototype.patch`, specs and `c0121.md` follow it. `design: ready`, as the lead directed: this was meant to be the approving round, and a review of this fix delta confirms it.

- F1: fixed: `serve.start` takes `Options.listen`, defaulting to `net.serve`, and always binds through it with `address = "http://127.0.0.1"`. A new `server.spec` case, "binds through its listener on 127.0.0.1 only, at the port it was given", wraps the real `net.serve` in a recording stub. It asserts exactly one bind, with `{ port, address = "http://127.0.0.1" }`, and that the server answers `/api/state`. Mutant N45 (bind `0.0.0.0`) and N47 (the option ignored, so the stub records nothing) are both killed. §3 and §2 say so, and a Rules row is added. Consequences: none; specs that don't pass `listen` get `net.serve`.
- F2: fixed: the guard case now has a draft #5 and a closed #9 on one branch, in both orders, and expects #5 as `draft`. Mutant N46 (a draft ranked as closed) is killed.
- F3: fixed: §4 now says retry "answers 202 once it has run for `serve.RETRY_WAIT` (1 s), or with the dispatcher's output if it exits sooner".
- Also, found while building c0118's implementation: the specs assumed z-nile's home is the repository root, but c0120's implementation puts it at `z-nile/`. They now run from any home: fixtures under the home's `.cache` (`pwd -P`), the checkout's files read from `git rev-parse --show-toplevel`, and fixture registries without a `home` key. No assertion changed.
- Also hardened: under machine load, the "never waits for gh" case raced its 0.3 s stub against the model build. The stub now takes 2 s, and the case resets the delay before any assertion, so a failure there can't slow the later cases.
