### F2 [high] The whole-gate digest holds declared refs only when the selection holds a `*` spec, so a `ref:`-only spec's ref can move and the whole gate is still reused; AC7 says otherwise and its case can't tell
Where: Design, `fingerprint.luau` third bullet ("HEAD plus declared refs when the selection holds a `*` spec") and "Whole-gate reuse" third bullet ("and, when the selection holds a `*` spec, HEAD plus the selected specs' declared refs"); AC7 ("includes HEAD for a `*` selection and every selected declared ref"); gate-reuse :: `headgate`; Rules R53.
Evidence: Both Design sentences make the declared refs conditional on a `*` spec. AC7 makes them unconditional. The only case, `headgate`, declares `*`, `ref:refs/remotes/origin/main` and `ref:refs/heads/declared` all on `b.spec`, so the mutant "declared refs only with a `*` spec" (what the Design literally says) passes every step: the selection always holds the `*` spec. With a spec `c` declaring only `ref:refs/heads/x`, the sequence fails open. `c` is selected by every change set (R60). Its per-spec fingerprint moves when `x` moves. But `x` moving with content, base and HEAD unchanged leaves the digest as it was, so `gate-check` prints `reused …` and `c` never runs.
Critique: This is the one skip c0165 allows besides a per-spec reuse, and it serves a gate whose spec would have rerun. No `ref:` line ships today (E9's named-ref audit), so the hole is latent until the first one, and zz-test's new wording invites that line ("`ref:` adds one named ref"). The tempting fix is to reword the sentences only. Without a case, the mutant still passes.
Consequences: An unconditional set of refs is the union of the selected specs' `fingerprint.refs`, the same set `gitState` already reads for the run. So it costs one more read only when no spec needs it, and nothing when none declares a ref. HEAD stays conditional on `*` (review 004 F3's fix).
Recommendation: Reword both sentences to "HEAD when the selection holds a `*` spec, and every selected spec's declared refs", matching AC7. Add a step to `headgate`, or a separate small case: a second spec `c` with only `ref:refs/heads/only-ref`; a gate passes and records; moving `only-ref` alone gives no `reused: an affected gate` line, and `c` runs again. Split R53 into its HEAD half and its declared-refs half, with the mutant "declared refs only with a `*` spec".
