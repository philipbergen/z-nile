### F2 [medium] `@game/ServerStorage/` counts only the default place's server roots: a second place's server root (pickman's lobby) is refused even once it maps the library, so the marked prep choice's cost is wrong
Where: Design 4 (`serverFile`, `srcAliasViolations(dir, roots?)`, which defaults to `graph.gameRoots()` and so to `default.project.json`); Design 2's prep choice "pickman's lobby place is not mapped … Cost if overruled: two lines in `lobby.project.json`, which the rule and the selector already accept"; Problem: "`@game/ServerStorage/` is allowed from server roots only".
Evidence: a probe in my clone gave pickman's `lobby.project.json` the two library nodes and appended `require("@game/ServerStorage/Arcade/Receipts")` to `src/lobby/server/Boards.luau`, which the lobby maps at `ServerScriptService/Lobby`. Results: `graph.serverFile("src/lobby/server/Boards.luau")` is `false`, `srcAliasViolations("src")` lists it, and pickman's `tests/meta/architecture.spec` fails `src requires: … (and ServerStorage/ on a server)` with `src/lobby/server/Boards.luau: @game/ServerStorage/Arcade/Receipts`. So the cost of the prep choice is the mapping plus a graph change, not two lines. The "who pays" chore will hit it: captured c0198 ("Pickman's … submit path use arcade's Hiscores and Boards; pickman's own copy is deleted") replaces Boards, which lives in `src/lobby/server`, while the lobby exists. The same happens to any home with a second place (Problem: "every project file"; the plan's N-place manifest). The design honours every project file for inputs (Design 4) and script roots (Design 3), but not for this rule.
Critique: the tempting fix is to union every project file's roots and apply longest-match. That accepts a folder that one place maps under `ServerScriptService` and another maps under `ReplicatedStorage`: Roblox replicates it in the second place, and a ServerStorage require then fails at runtime there.
Consequences: a file has one owner per place. The rule becomes "a server file in every place that maps it, and mapped by at least one". `srcAliasViolations` needs the mappings of every project file of the home, read through the one reader (`graph.mappings`, with the project-file listing `placeInputs` already does, so the two must not drift). A file that no place maps stays a non-server file.
Recommendation: `serverFile(file, places: { { GameRoot } }?)`, defaulting to the roots of every `*.project.json` in the current folder. True when at least one place maps the file and every place that maps it does so under `ServerScriptService` or `ServerStorage` (longest path within each place). graph.spec cases (promoted, since this is a rule): a second place mapping `src/lobby/server` at `ServerScriptService/Lobby` gives a server file; the same folder mapped at `ReplicatedStorage/X` by a third place gives not one; and `srcAliasViolations` over two places. Add rows with mutants "default place only" and "any place says server". Then correct the prep choice's cost line to match.
