## Candidate lessons
- z-design, "a fix that removes a forced workaround re-exposes the steps the workaround satisfied". Rule: when the defect made the protocol fall back to a workaround (here a second `./zn finish`, which left the layer one commit), list the later protocol steps and rules that passed only because of that workaround, and run each one on the fixed prototype. Why: d0333 design review 001 F3 and F4. The forced second finish was what made Phase 5's verify-first `--check` pass and kept `start` off a lower layer with a post-finish commit. With the fix, both changed. Check: which steps after the fixed point passed only because the bug forced the workaround, and has each been run on the prototype?
- zz-arch, "widening one judge of a state means asking every judge of it". Rule: when two functions judge the same state (layergit's finished layer, trace's one-commit lower layer), a fix that widens one moves the refusal to the other, later in the flow. Why: d0333 design review 001 F4. Check: for each state the fix makes reachable by the prescribed command, which other functions judge that state, and do they agree at the same step?
