# Answers to design review 003: c0132

- F1: fixed: AC2 names both new cases ("a specs group pgrep fails to read is unread, even when the launcher's own line reads", "the launcher's own line not found is unread, even when the specs group reads"). `report()` now also judges the spec's whole run (`whole_run`): a failing case that no criterion names fails every criterion, and so does a spec case no criterion names. "sets up" and "cleans up" need no criterion, but a failure of either still fails every criterion. The named set is read from check.sh's own case lines, so it can't drift from the criteria. Every "run" row's mutant was rerun through `./zn check c0132` on the prototype, not the spec alone; E5 records the result per mutant. Consequences: a future case added to the spec without a criterion turns every check red until it is named; that is the point: the Test plan and check.sh move together.
