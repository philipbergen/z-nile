# c0184: Scaffold arcade homes

## Problem
The user, 2026-10-31: "I want to branch out into multiple games, they will each have their own directory in the project: first person snake, first person asteroids. I also want a new project for a landing portal where you can scroll between the games and see the highscores for each, the same cost model remains but it shoudl show 5 robux for each game witha slash through showing it is currently on sale for 1 robux. highscores shoudl show how many revives were used." Then, on the plan: "Add a third game first person asteroids."

After c0183 registers `arcade`, `portal`, `snake`, `invaders` and `asteroids`, their homes hold only a `.tracker/`. Before any game code can be written and gated there, each home needs what pickman's has: `check.sh` (exec of `z-nile/check.sh --project <name>`), `.luaurc` (with an `@arcade` alias to `../arcade/src/shared/Logic` in every game home), `tests/run.luau`, `src/`, a `default.project.json` (the library's a harness place), `selene.toml` and `stylua.toml`, and the `<name>-arch` and `<name>-test` skills linked by `./zn skills`.

Several tooling paths name pickman by hand, so a new home would be skipped or misread:
- `scripts/hooks/stop.sh:16` (`^(src|tests|z-nile|pickman)/`);
- `z-nile/tests/lib/cachepaths.luau:18` (`"pickman/scripts"`);
- the root `.luaurc`'s `logic` and `shared` aliases, which point into pickman;
- `.github/workflows/deploy.yml` paths-ignore, so every new project's tracker push would trigger a deploy (should be `'**/.tracker/**'`);
- the board's title.

What should happen: every new home is scaffolded and gated like pickman's, and those paths come from the registry, so a sixth project needs no tooling edit.

## Non-goals
- Selecting and gating code shared across homes (`../arcade` `$path`s, cross-home requires): c0185.
- The N-place deploy: captured in portal after c0183 lands.

## Solution
- Prefer reading homes from `z-nile/projects.toml` (`z-nile/roots.luau`) everywhere a path names pickman.
- Builds on c0160 (third-project check paths), which proves the check-paths rules with a fixture third home.
