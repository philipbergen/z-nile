# Answers to design-review-005 (c0191)
Seven findings are fixed; F1, the round's high, is a question about what "the agent ends" means for a subagent. It cannot be settled by the author (z-design 5.4: a final round with a high goes to the user whatever was answered): the Design carries a recommended reading, an experiment, three options and their costs for the user to rule on.

- F1: put to the user. Experiment E16 (a background subagent started a `run_in_background` command and returned): the harness kept the subagent open until the command ended (154.9 s for a 150 s command), so the command and the agent end together; for a foreground subagent the docs say its commands stop when it ends. The Design's reading (a): nothing stops a subagent's command before its own limit while the subagent waits for it; the pinned sentence is true in that sense. Options (b) refuse `run_in_background` in subagent calls, (c) a `SubagentStop` mechanism, and their costs are in the Design ("The agent's end"). Observed OC3 shows reading (a). consequences: if the user rules for (b) or (c), the hook or the session-end hook changes and a round 6 is needed (the rules allow only five; a re-prep after a scope decision restarts the count).
- F2: fixed: `reap.scope(main, uid, temp, roots)` is the pure default scope (roots, scratch prefixes, `sessionAnywhere`), `reapRun` calls it, reap.spec exercises it (default, explicit root, a main checkout with a dot, no temp folder) and runs `decide` over the incident with its output, not with hand-made options; a docs case pins that the engine calls `reapLib.scope(`. consequences: eight lines moved out of `main.luau`; four mutants killed (session flag, slug, roots, a copy of the logic).
- F3: fixed: the `cd` reading comes from `split`'s commands (a `cd` moves the folder for the commands after it; an operand with `$`, `~`, a backtick, `-` or none leaves the folder unknown and refuses the tooling match), and the here-document owner is the last simple command `split` reads before the `<<` (so `bash 2>&1 <<E` is read), with `<<\E` accepted. Cases both ways: `cd "$X"`, `cd '/tmp/x'`, `cmd; cd /tmp`, `echo "cd /tmp" && ...`, `python3 - 2>&1 <<E`, `python3 - <<\E`. consequences: the Design's sentence about `cd` is exact.
- F4: fixed: `mkdir`, `rm`, `rmdir`, `cp`, `mv`, `touch`, `ln`, `chmod`, `[[`, `]]`, `read`, `basename`, `dirname`, `realpath` end by themselves; the file after a redirection and the value of `-n`/`-c`/`-e`/`-f`/`-s`/`-d` are no operands, so `cat > out` and `head -n 5` read stdin and are refused in a background call. The 859-call corpus still shows no gate-shaped call refused. consequences: none.
