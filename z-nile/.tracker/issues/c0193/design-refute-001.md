# Design refute 001: c0193 (answers to design-review-001)

- F1: fixed: the driver counts the texts each case returned on and keeps the first error; `hostile.finishes` fails a case that raised on every text (`<case>: raised on every text, so the sweep never ran it: <error>`); `Case` gains `prefix`, put before every text; `finishes.spec`'s `REFUSES` fixture now refuses only texts with a backslash, and new cases pin the failures of a never-running case (a fixture and a typo'd real module call) and of the prefix (a fixture that returns early without its head); `tree.spec`'s raftcheck case now also requires the case's `prefix` to contain the RC0 head's last line and to end with `check "RC1: `. Consequences: a new field and rule (a case must reach its scanner's loop), Rules rows and mutants for each (count check removed, prefix dropped), Design text; `scanners.spec` passes unchanged on the six real cases (every one returns on some texts). Confirmed with a mutant that restores the typo.
- F2: fixed: `hostile.bounded` raises unless `seconds` is a whole number of 1 or more (naming the value), and so does `finishes` through it; `finishes.spec :: refuses a limit that is not a whole number of seconds` tries 0.5, 0, -1, 1.5 and NaN before anything starts and a plain 1 works; the zz-test bullet and the Design say so. Consequences: rejecting rather than rounding up (rounding would quietly change the caller's limit); one Rules row with its mutant.
- F3: fixed: the wrapper traps INT, TERM, HUP and PIPE and kills the group before it exits (130, 143, 129, 141); the command runs under `ulimit -t seconds+1` through `/bin/sh -c` (E12: the kernel stops an orphaned spinner on macOS, 2.0 s of CPU for `ulimit -t 2`); a command that died of signal n returns `128 + n`. New cases: a command that sends TERM to its own parent leaves no grandchild and returns 143; a command that kills itself with KILL returns 137; `ulimit -t` inside the command prints `seconds + 1`. The helper and c0191's runner are the same job: the Design and the report tell the lead to pass this to c0191's prep (one runner). Consequences: SIGKILL of the wrapper is covered only by the CPU limit (said in the Design); `sh -c` is a fixed string with arguments, not a built command; rows and mutants added (handler removed, exit code, limit removed).
- F4: fixed: the proof states its whole obligation (Design, "What proven means"): the only assignments to V in the body are further steps in the same direction (a reset, a step back, a `local`, a `for i` void it; a branch that takes a value by stepping again does not); the bound is a number, a name, a dotted path or `#name` that the body never writes (a `table.insert(B`, an index or field assignment, a method call, `math.*`, a call or a compound bound void it); the end is found by structure (the first line at or above the loop's indentation must be `end`, with an optional trailing comment, or `until` for a repeat). Spec cases for every shape the review gave, the same-direction and read-only cases that must stay proven, and the end-by-structure case. Consequences: the proven count on `main` falls from 10 to 6 and the list grows from 26 to 30 entries (the breadth-first walk of `cleanup.luau:32` joins it, as the review found, and three loops with compound bounds); E3, the seed in `prototype.patch`, step 5 and the criteria are updated; the review's own example of the mis-ended loop is a spec case.
- F5: fixed: Existing work now carries the per-branch table with the search used (16 problems in 5 files on `impl-c0117`, 14 on `impl-c0118`, 15 on `impl-c0121`, 1 on `R0061`, 2, 1 and 1 on three branches with no PR yet; measured with this design's stricter lint, so they differ from the review's counts), what each raft does after a rebase, what this raft's executor does for any that lands first (Implementation step 5), and that the lead tells the leads of R0052, #122 and #123, not only #125's author. Consequences: none to the specs; the contention on the shared blocks of `loops.ALLOWED` is named.
- F6: fixed: `hostile.ALPHABET` gains `[`, `]`, `=` and tab (16 characters, 69,905 default texts); `scanners.ALPHABET` adds `.`, `/`, `@`, `~` (texts over it up to length 3, plus the needles beside every character); `scanners.spec` reads each case's module and fails on a one-character literal it compares with that is not in the alphabet or on `scanners.EXCEPT`, with a case that pins the reader; `texts.spec` no longer pins 12 or 22621 (it pins the sum of the powers of the alphabet's size, the incident's characters and the long-bracket, tab and assignment characters). E5 and Scalability are restated for what ships (74,197 texts, about 2 s). Consequences: the sweep costs a little more; `EXCEPT` is a new reviewed table (empty today).
- F7: fixed: AC9 greps `^sources:.*c0193`.
