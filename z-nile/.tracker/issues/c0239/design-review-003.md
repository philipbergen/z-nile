## Candidate lessons (for the lead)
- zz-test: what a case's change set must not see goes into the fixture's base commit, never into a commit on the work branch, whenever the code under test diffs against a merge base. Why: c0239 design review 003 F2. stop.spec committed its stub gate and its declarations on `work`, so every case's change set held them, and the spec failed the right `scope` and passed its mutants. Why: c0239 design review 003 F1. narrow.py replaced one of four `toBe("full")` lines, which made AC4 impossible to pass. Check: does the substitution list come from a search over the base file, with its count asserted?
