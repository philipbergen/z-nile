# c0240: A merge failure teaches the selector

## Problem
From the user (2026-10-26), part of c0165's capture "Reuse passed test results":

- **A merge failure teaches the selector**: when the merge's full gate fails a spec that the affected selection didn't pick for the same change (a graph miss), the tooling finds out how the affected selection missed it (which changed file the spec depends on without a require edge) and records that dependency, so later affected runs select the spec. This replaces zz-test's "Graph miss: file a chore by hand" rule.

Scope decision (user, 2026-10-26): learned dependencies go "DB now, and printed to commit": the edge goes into the SQLite db at once, and the gate prints the line to add to a committed file that the selector reads; the gate itself never edits the repository.
Decided with the user (2026-11-03): red `main` first shows at `./zn done` and the merge (c0239); this issue's base trial is how a failure there is told from the raft's own.

Needs c0165's store and selector, and c0239's gate placement.

Split from c0165 (user, 2026-11-03: "Split it"), which had grown to a 600-line design and a sixth review round; c0165 keeps the fingerprint, reuse and store outcomes, and this issue keeps the outcomes below. Every outcome is the user's 2026-10-26 capture, not narrowed.

Prior design work: c0165's prep branch `prep-reuse-test-results` (commit a03b4995; `z-nile/.tracker/issues/c0165/`: the design, six review rounds and their answers, and the acceptance specs) holds a design for the whole of c0165; this issue's prep takes the part that is its own.

## Non-goals
- The fingerprint, reuse and store: c0165. Gate placement: c0239.

## Solution
- Find the edge by bisecting the changed files against the failing spec, or by diffing the spec's file reads against its require closure.
- Learned dependencies: commit them as extra edges that `affected.luau` reads (a `deps` table beside the spec, or one registry file), so every checkout and CI benefits and review sees them; keep them only in SQLite if local is enough.
- Specs that read files outside their requires need declared inputs (shared with c0165) or must always run.
- A failed spec that was selected is an ordinary failure; the base trial of any failed spec must skip a spec absent at the merge base (it fails there only because it doesn't exist).
