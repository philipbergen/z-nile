# c0268: Readme drop intent reading rule

## Problem
c0264 adds an `## Intent` section to `z-nile/README.md` whose closing sentence is a reading rule: where an older line naming the same ticket as a newer sub-section differs, the sub-section follows the ticket's current capture, and a line with a worker design means a draft that a person approves. What should happen: once the README lines themselves say it, that closing sentence is removed from the Intent.

Scope decision (user, 2026-11-08): "humans approve the design, humans interact (plan mode) over the idea". c0264's Design: the rule is the last of the follow-ups, to be removed once c0252 (Autonomous delivery), c0253 (the worker end and the picture's `design` step), c0249 (`claimable`, "gets a rank"), c0254 (the `preparing` claim and its lost-race line), c0251 ("round one Opus") and the dispatcher chain's `design` step (c0267) have reworded their README lines. It also needs c0264 merged, since the Intent does not exist before.

## Non-goals
- Rewording any older README line: each of c0252, c0253, c0249, c0254, c0251 and c0267 does its own. This chore removes only the Intent's reading rule.
