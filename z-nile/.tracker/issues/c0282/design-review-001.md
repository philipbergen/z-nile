Critique: the gate's own rule is that it "judges each item's change by its shape against the base, never by what the PR says" (dispatcher.luau:1293-1296), but the record is judged by its event alone, so a row on an issue the PR does not raft, or one naming another raft, lands on main with no human, and c0280 prints it. PRs 61-64 become refusal cases that assert their reasons; Rules rows with the mutants `gate takes a record without a raft: change`, `gate ignores the row's raft`, `gate takes any stored actor`.
