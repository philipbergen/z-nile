# c0288: C0260 spec stall limit holds under load

## Problem
c0260's sequestered spec z-nile/.tracker/issues/c0260/acceptance/dispatch.spec.luau sets stall_seconds = 5 in its fixture's models config, the same short limit that made c0117/dispatch-cli.spec.luau fail under load until c0279 (R0089, merged 2026-11-09) raised it to 120 s: on a loaded machine (load 47 to 97 on 18 cores) a fake step that is quiet while it works is killed as stalled. c0260 is prepared (#257), so the spec would be promoted as is when its raft runs. Found by R0089's code reviewer. What should happen: c0260's dispatch spec stays green on a loaded machine; only a case that tests the stall itself keeps a short limit, as c0279 did for c0040.
