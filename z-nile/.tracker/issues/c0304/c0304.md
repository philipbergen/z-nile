# c0304: Workstreams stale cases

## Problem
- Two promoted cases in `z-nile/tests/acceptance/c0045/workstreams.spec.luau` ('worktree --from bases the new worktree on the ref' and 'stream review files are not review rounds') fail on unmodified main since #296, because the first bases on a branch `R0010-demo` that a raft worktree no longer makes and the second is refused by done's published-layer-tip check before it reaches the review check.

## Non-goals
- No file other than `z-nile/tests/acceptance/c0045/workstreams.spec.luau` changes, so no tooling behaviour (including #296's detached raft worktrees and done's published-tip check) is altered.

## Solution
- Both cases are narrowed to set up what #296 makes (a ref that exists; a local layer tip that is the published one) while still asserting that `--from` bases the new worktree on the ref's tip and that done refuses with 'no review-NNN.md' when only stream review files exist, and both pass on main with every other case in the file unchanged.
