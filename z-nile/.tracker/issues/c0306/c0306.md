# c0306: Commands refuse a review off the review models

## Problem
- `./zn status <id> prepared` today accepts an issue whose design review was recorded on any model, for example `claude-sonnet-5-5`.
- `./zn done <R-id>` today accepts a raft whose layer code reviews or final review of the stack were recorded on any model.
- No command defines which recorded models count as review models, so nothing catches a lead who forgets to run a review on one.

## Non-goals
- The commands do not verify that a typed model id is the model that actually ran the review.
- This change does not alter `.models.toml`, the roles table, or which model the dispatcher picks for any stage.
- This change does not build the cross-model review pool, which stays with c0251.
- This change does not re-review or re-record any review made before it lands.

## Solution
- A review record counts as "on a review model" when its model id starts with `claude-opus-` (on any CLI, `claude` or `cursor-cli`), or starts with `kimi-code-k3`, or starts with `grok-` and its recorded effort is `xhigh`.
- By that rule `claude-opus-4-1`, `claude-opus-5-5[1m]`, `kimi-code-k3.2` and `grok-4.7` at `xhigh` pass, and `claude-sonnet-5-5`, `claude-fable-5-2` and `grok-4.7` at `high` are refused.
- The three patterns are one fixed list in the tooling's code and are not read from the ids in `.models.toml`, so changing `[roles.final-review]` or a fallback to another id of the same pattern refuses no item.
- `./zn status <id> prepared` refuses an issue whose design review is not on a review model, and the refusal names the recorded model and the three patterns.
- `./zn done <R-id>` refuses a raft when any layer's code review, or the final review of the stack, is not on a review model.
- A stream review is never judged by the rule.
- A review record carries the model id and the effort it ran at, and a `grok-` record with no effort is refused.
- For an interactive review the record holds the model id and effort the lead types, and the commands judge that typed value like any other.
- An item whose first review record is dated before this change lands is exempt from both refusals.
