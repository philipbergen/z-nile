## Problem
Carried from c0261 (Model tiers), which the user retired on 2026-11-12 ("Retire, file leftovers": #299, the roles table, already names a real model for every stage, so c0261 was closed and what main still lacks was filed as new tickets). c0261 was designed on the pre-#299 .models.toml; its prototype proto-c0261 (be21970f, base 10dd3c85) is a reference only.
