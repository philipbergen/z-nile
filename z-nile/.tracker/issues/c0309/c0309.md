# c0309: Lesson: Order names each member once

## Problem
- `z-nile/skills/z-raft/lessons/order-names-members-once.md` already forbids a repeated member id in a raft's Order, but it does not name the layer-branch form (such as `R0090/1/c0261`) as a repeat, and it does not say to run `./zn stack <R-id>` on the rafting branch before the rafting pull request; R0090's rafting (#321) wrote both `**c0261**` and `R0090/1/c0261`, and `./zn start R0090` refused with "c0261 is listed twice in R0090's Order" only after the raft was readied.

## Non-goals
- This adds no new lesson file, changes no engine or gate behaviour (`stack.order` and `./zn status`/`ready` stay as they are), and does not fix non-member ids in existing rafts' Orders, which is d0295.

## Solution
- Extend that existing lesson with a note that cites R0090 (#321), names a layer branch such as `R0090/1/c0261` as a second naming of its member, and says to run `./zn stack <R-id>` on the rafting branch before the rafting pull request is opened, so that `./zn lessons Order layer branch` finds it.
