# c0310: Watch whole tree specs

## Problem
- A change to a file that c0193's meta, tree and scanners specs or c0192's meta case would scan does not select those specs under `--affected` unless the file is in today's hand-kept list, because the `*` lines in `inputs.tsv` are unread (R0072 review-001 F3).

## Non-goals
- This issue does not select a whole-tree spec for a changed file it would not scan (for c0193's lint: anything under `.tracker/`, `tests/acceptance`, `tests/fixtures`, `vendor` or `.cache`, any `*.spec.luau`, and any non-`.luau` file), and it does not change c0180 AC8's declarations beyond reading them.

## Solution
- The watch map gains a whole-tree selector under which a spec declares its roots, its skipped folders and the kind of file it reads, and `--affected` selects that spec exactly when a changed file is under a declared root, outside every declared skip and of the declared kind.
