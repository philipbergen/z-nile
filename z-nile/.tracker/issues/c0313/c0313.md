# c0313: zz-review states which challenges use the author's model

## Problem
- `z-nile/skills/zz-review/SKILL.md` line 18 states "A challenge is never run by the model that wrote the text" and, in the same paragraph, that `design-challenge` names no author and raft-mode review uses the `raft` role so both sides run on Opus, which contradicts the first sentence for design and raft reviews.

## Non-goals
- No change to `.models.toml`, to which model any role or mode runs on, or to any file outside `z-nile/skills/zz-review/`.

## Solution
- The Reviews paragraph of `z-nile/skills/zz-review/SKILL.md` no longer contains the sentence "A challenge is never run by the model that wrote the text" and instead states one rule per mode: `idea-challenge` and `code-review` drop the author's model, `design-challenge` and raft-mode review run on the author's model, with the reason for each.
