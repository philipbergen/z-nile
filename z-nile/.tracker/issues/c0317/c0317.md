# c0317: A takeover writes a provenance record

## Problem
- A successful takeover of a lost claim (`./zn status <id> preparing` on a lost stamp, c0274) writes no provenance record, so nothing records which session took the item over.

## Non-goals
- This issue changes neither how a lost claim is detected (c0274) nor the format or storage of provenance records (c0263).

## Solution
- Every successful takeover of a lost claim writes exactly one provenance record through `./zn provenance record` (c0263), naming the item and the session that took it over.
