# c0323: Cross prep conflicts c0250

## Problem
- With c0256's build and the prototypes of c0263, c0248 and c0250 merged, three c0263 restack cases fail, c0262's work spec reads a `RaftFact.questions` field that c0250 removes, the tooling's `main.luau` has 205 top-level locals against Luau's limit of 200, and `work next` can say to run `./zn done` when `done` then refuses a member's layer review.

## Non-goals
- This issue changes no behaviour, public signature or approved design document of c0248, c0250, c0256, c0262, c0263 or c0306 beyond the one reconciliation named for each of the three pairs, and the `main.luau` fix moves code without rewriting any of it.

## Solution
- Each of the three cross-design disagreements (c0248 with c0263, c0262 with c0250, c0306 with c0248) is settled in the layer that lands second, and `main.luau` is brought under 200 top-level locals only by moving existing declarations unchanged into modules it requires, so the merged tree passes the restack spec, c0262's work spec and the Luau compile.
