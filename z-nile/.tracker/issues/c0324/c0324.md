# c0324: Idea keeps decided lines

## Problem
- `./zn idea` on c0306, an issue that already had a Problem carried from the retired c0261, drafted a new Problem without its four "Decided with the user" lines and its carried-from note, which survived only as Solution bullets and in `./zn capture`.
- z-ticket steps 4 and 6 say to land the idea's files with `./zn land`, but land refuses them ("not a capture change: ... changes idea:") and, after the idea's PR, refuses the spend-only capture record ("a capture's spend record belongs to an issue document this land changes").

## Non-goals
- This issue does not change how `./zn idea` drafts or challenges the Solution and Non-goals sections.
- This issue does not restore lines already dropped from issues that earlier idea runs rewrote.

## Solution
- After `./zn idea` runs on an issue whose Problem holds Decided lines, Scope decision lines or a carried-from note, the new Problem section itself holds each of those lines word for word, and a run whose Problem lacks any of them fails even when the line appears elsewhere in the issue.
- `./zn land` accepts a challenged idea's files and the capture's spend record, or z-ticket steps 4 and 6 name the PR path for the idea and say the spend rides with the prep.
