# Design refute 001

- F1: fixed, by the user's ruling (2026-11-15, "c0325 adds it", a Decided line in the Problem): every authored step records its model where the item travels. That is the spend row's model cell in the item's `spend.d`, plus the `Issue:` trailer for a commit. The dispatcher sets `ZN_MODEL` per attempt, and an interactive lead types `--model`, refused when omitted in a marked item (Prep choices). `authorship.luau` and `authorread.luau` read it per review mode (Design outcomes 1 and 2, AC3–AC7). consequences: c0325 grows to about 480 lines and `depends_on: [c0306]` (the mark, typed-wins, `isModel` with brackets). The promoted fixtures that commit or prep-spend in a marked item gain `--model` (Overrides, measured in E4). d0328 is no dependency, because a typed or env model covers every authoring step and `commit` never measures. c0251 reads `authorship.of`.
- F2: fixed: the writing role is an input (`authorship.ROLES`, step to role), not `Resolved.author`, so design-challenge, the raft role and final-review get an answer (AC3), and a record is recognised by every model the loaded toml names (`models.knownModels`, AC1). consequences: `Resolved` gains no field. The first design's `Resolved.author` and its cases are dropped.
- F3: fixed: `authorship.isAuthor` normalises both sides with `models.bareModel` (one trailing `[...]` removed), so identical bracketed strings match and `[1m]` against plain matches both ways (AC2). consequences: `[1m][2m]` keeps one marker, which a case pins.
- F4: fixed: precedence is live, then rows, then `authorModel` (where `./zn idea` stores the real writer), then the writing role's first choice. An empty string counts as none (AC3). consequences: the idea path also passes `live = wrote`, so it reads `recorded`.
- F5: fixed: `modelOf` takes the longest known model followed by an optional marker and any effort word, so a record at an effort no role uses now, or a typed `<model>-<effort>` id, is recognised (AC1). The Guards bullet now says the match fails "visible" (`assumed`/`unknown`), not closed. consequences: a documented limit. A model unknown to the toml that shares a known model's name plus `-word` is read as that model.
- F6: fixed: the mutant "strip only the author role's effort" is M3, killed by the AC1 case with an effort no role uses. The rest of the table is rebuilt for the redesign (M1–M19, run on the new prototype). consequences: none.
- F7: fixed: `authorship.of` returns each writer with a provenance, `recorded`, `assumed` or `unknown`, and the step it wrote (AC3). A stand-in is never reported as recorded (M11). consequences: c0251 can flag an assumed author, which its 2026-11-15 rulings already flag on the board.
- F8: fixed: E1–E4 and the mutation check record how each run was bounded (`./zn run --time …`, or a spec-runner or gate run). consequences: none.
