# Idea review 001

## Findings

- F1: The Solution's second clause ("nothing that reads a red run's results can take them for a green run's record") answers a problem the Problem never states. The Problem is only about a red run's failures being pinned on the wrong criteria; it says nothing about red results being mistaken for a green record. So either the Problem is missing a sentence about that risk, or the clause goes beyond the smallest solution. "Nothing that reads" also covers every possible reader, so no one could show it false. To be checkable, it would need to name the readers it means, such as the gate or a cached green record.
