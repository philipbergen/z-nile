# c0332: AGENTS.md names the review models

## Problem
- AGENTS.md line 7 says design and code reviewers are pinned to Opus 5.5, but `.models.toml` gives the `final-review` role `claude-fable-5-2`, so a lead following that line starts a final reviewer on the wrong model.

Scope decision (user, 2026-11-15), c0251 design review 001 F7: "Move it to c0332 (Recommended)". c0251's confirmed Idea said AGENTS.md's reviewer line changes with it. That outcome lives here instead: this issue rewords the line once c0251's tier rule exists, and depends on c0251.

## Non-goals
- This issue does not change `.models.toml`, zz-review, or the list of recorded review models that c0306 makes `./zn status`, `ready` and `done` accept, and AGENTS.md does not point at that list.

## Solution
- Once c0293 and c0306 have landed, AGENTS.md line 7 names no model and says instead that the exception to the sonnet default is a reviewer subagent, which runs on the model `.models.toml` names for its review role, as zz-review's "Who reviews" states.
