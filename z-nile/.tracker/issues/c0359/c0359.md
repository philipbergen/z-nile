# c0359: Prep gate merges unlinted folders

## Problem
The dispatcher's prep and raft gates (auto_merge in .models.toml) merge a PR on CI green plus the tracker-state shape, and CI (.github/workflows/deploy.yml) runs no gate, so a prep whose issue folder fails the full gate's format or lint stage (stylua --check, selene over every .tracker) lands on main and turns z-nile's static stages red for every later land, done and full gate; c0292's prep (E3, 2026-11-15) found three such dispatched prep PRs open, green and mergeable: #397 (c0230, stylua), #399 (c0301, stylua) and #408 (f0339, stylua and selene). The gate a dispatched merge passes must run at least the static stages over the PR's changed item folders, or refuse it.
