# c0364: Roadmap spec watches readme

## Problem
- The promoted specs of c0115, c0116, c0117, c0118, c0183, c0184, c0185, c0246, c0259 and c0264 read `z-nile/README.md` as text, but no `watch.txt` under `z-nile/tests/acceptance/` lists that file, so a README change selects none of them under `--affected`.
- On 2026-11-15 R0100's re-pick left two Roadmap rows each for c0265, c0274, c0275 and c0277; every affected gate, the raft check and done's gate passed, and only R0099's coherence review 003 caught it before it would have landed red under `--full`.

## Non-goals
- The selector's dependency logic does not change: the fix is `watch.txt` entries only.
- The duplicated Roadmap rows are not repaired here: they are not on main and belong to c0365.

## Solution
- A change to `z-nile/README.md` selects, under `--affected`, every promoted spec that reads that file as text, c0264's `roadmap-unique.spec.luau` and `intent.spec.luau` included.
