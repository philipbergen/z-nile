# c0368: Approve specs answer explainer page

## Problem
- c0283's promoted approve specs (`tests/acceptance/c0283/approve.spec.luau`, `tests/tooling/approve.spec.luau` and `tests/tooling/approve-publish.spec.luau`) run `script -q /dev/null ./zn approve <id>` on a fixture with no `explainer.html` and no answer typed at the terminal, so every recording case fails once f0339 makes approve refuse a missing page, open the page and read y/n from `/dev/tty`.

## Non-goals
- This chore changes no behaviour of `./zn approve` or any other command and adds no explainer check: it only narrows the three named specs (recorded as Overrides of c0283), and f0339, which depends on it, keeps the page, opener and y/n behaviour.

## Solution
- After c0283 is done, each recording fixture gets a committed `explainer.html` whose `zn-contract` the spec computes with `approval.collect` and `contract.hash`, a stub `open`/`xdg-open` first on PATH, and the invocation `yes y | script -q /dev/null sh -c './zn approve <id>; echo zn-exit=$?'`, where `script` forwards its piped stdin into the pseudo-terminal it creates, so approve's `/dev/tty` read receives the `y` (f0339 E1 and E2), today's approve never reads it, and the three specs pass both before and after f0339 lands.
