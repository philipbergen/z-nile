# c0372: Land means implementation merge

## Problem
Nomenclature (user, 2026-11-15): "along the way there are many merges and the final one that actually merges an implementation we will use meta's 'land' terminology. Please update all the right places". Today z-nile says 'land' for any merge to main: a capture (./zn land, 'tracker: new'), a prep PR, a rafting PR, 'Landing a change' in zz-rules, and the raft's implementation PR alike. What should happen: 'land' (lands, landed, landing) names only the final merge of a raft's implementation into main (what ./zn done completes); every other merge to main (capture, idea, prep, rafting, scope and tracker-state PRs) is called a merge. The skills (13 files use the word today), z-nile/README.md, AGENTS.md, the templates, the command usage and messages of ./zn, and the board say it that way, with one short definition of both words in zz-rules. Open for the idea: whether the ./zn land command, which publishes a capture, is renamed (a guess to put to the user: yes, with the old name kept as an alias that prints the new one), and whether the 111 lesson files that use the word are rewritten or left as history.

Decided with the user (2026-11-20): "use best judgement, just make them consistent" on the open tickets that each edit AGENTS.md and the skills' shared Lessons section (the lead's judgement: c0293, c0316, c0372 and c0394 are designed against each other. c0293 moves whatever text stands at the time it is built, as it stands; each of the other three edits its paragraph wherever it then lives, AGENTS.md or the skill c0293 moved it to; c0316 and c0394 both change the Lessons section, and the one built second applies its edit on top of the first's. Each of the four names the other three in its regression guard.)

Decided with the user (2026-11-20): "c0372's rename of 'land': yes" (the capture command `./zn land` is renamed, so that "land" names only a raft's implementation merging to main. The design proposes the new name. The open tickets written around `./zn land` for captures, c0258, c0260, c0316 and c0324, follow the new name, and this ticket names them.)
