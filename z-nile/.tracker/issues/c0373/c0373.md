# c0373: Beta publish only for game pull requests

## Problem
- `.github/workflows/deploy.yml` runs `pickman/scripts/deploy-beta` for every non-draft pull request from this repository, so each one publishes a new version of both Pickman (Beta) places (game and lobby) whatever files it changes.
- On 2026-11-15 several tracker-only prep pull requests each published new versions within a few hours (the latest: game version 21, lobby version 33, at 12:45 PST), while no game source had changed on main since 2026-11-05.
- The same afternoon the user met a join that hung at "joining server" and worked on a retry; the cause is not confirmed and the repeated publishes are only a suspect.

## Non-goals
- What is published and to which places stays as it is (c0210, N-place deploy, owns that), including any Beta publish of the other games or the portal.
- No publish is added on a push to main.
- The cause of the "joining server" hang is not investigated or proven here.
- Draft pull requests and pull requests from forks still publish nothing, as today.

## Solution
- A non-draft pull request from this repository publishes to Beta exactly when it changes at least one path in the publish set, which is the three groups below and nothing else.
- Place inputs: `pickman/default.project.json`, `pickman/lobby.project.json`, anything under `pickman/src/` (the lobby, `pickman/src/lobby/`, included) and anything under `arcade/src/`.
- Deploy code: `pickman/scripts/deploy-beta.luau`, `pickman/scripts/lib/beta.luau`, `pickman/scripts/lib/opencloud.luau`, `z-nile/lib/sh.luau` and `pickman/.luaurc` (it resolves the script's `@scripts` and `@znile` requires).
- Deploy run: `.github/workflows/deploy.yml`, `z-nile/setup.sh` and `rokit.toml` (the pinned tools that `z-nile/setup.sh --tools` installs).
- A pull request that changes no path in the publish set publishes no version of either place, gets no "Published to Pickman (Beta)" comment, and its deploy check does not end as failed.
- A pull request that changes only `snake/`, `invaders/`, `asteroids/` or `portal/` publishes nothing, because no Beta place is built from them.
- A pull request that changes only tracker documents, skills, or z-nile files other than `z-nile/lib/sh.luau` and `z-nile/setup.sh` publishes nothing.
- A check fails when a `$path` in either Beta project file, or a non-`@lune` require reachable from `deploy-beta.luau`, names a file outside the publish set.
