# c0387: Fence scan watch misses new specs

## Problem
- A change that adds or edits a spec under `tests/` that `z-nile/tests/tooling/repo-fence.spec.luau` scans (as R0112's bind commit added `z-nile/tests/acceptance/c0371/check-paths-homes.spec.luau`) selects no fence spec in `z-nile/check.sh --affected`, so `./zn done` passed c0371 to main with the fence red.

## Non-goals
- The six homes' `tests/meta/fence.watch.txt` lists stay as they are, so such a change does not select any home's `tests/meta/fence.spec.luau`.

## Solution
- A change that adds or edits any file the repository fence scan reads selects `z-nile/tests/tooling/repo-fence.spec.luau` in `z-nile/check.sh --affected`, so `./zn done`'s affected gate on the done tree fails when that file breaks the scan.
