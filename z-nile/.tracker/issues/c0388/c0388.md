# c0388: Board count spec reads every root

## Problem
z-nile's full gate is red on main on tests/acceptance/c0042/cli.spec.luau ('the real tracker's page shows every raft and issue': expected 102, got 103) since the rafting of R0110 merged (#453, 2026-11-15 15:53 PST). R0110 is the first raft in arcade's root; the board page shows it, and the spec counts raft and issue folders in a hand list of two roots (pickman/.tracker and z-nile/.tracker, their backlog, active/ and done/), so the page has one raft more than the spec finds on disk. The page is right and the spec's list is stale since c0183 registered the arcade's projects. It blocks every raft whose check runs the full gate or c0042's spec: R0100 (c0276's AC3) and R0072 (RC0, full) today. What should happen: the spec counts the folders of every root in z-nile/projects.toml (read from the registry, never a hand list), for rafts and for issues, and passes on main with R0110 as it is.
