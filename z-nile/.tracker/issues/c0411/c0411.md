# c0411: Rounds spec reads every root

## Problem
- With the `./zn metrics` crash (d0406) fixed, the case 'lists every raft once, sorted by id' in `z-nile/tests/acceptance/c0043/rounds.spec.luau` fails with 'expected deep-equal values', because it builds its expected rafts from a hand-written list of two roots (`pickman/.tracker`, `z-nile/.tracker`) while `./zn metrics` lists the rafts of all seven projects registered in `z-nile/projects.toml`.
- `z-nile/tests/acceptance/c0116/retired.spec.luau`, which runs `rounds.spec` in a clone, is red on main today because of the d0406 crash alone, and with d0406 fixed it stays red because of the hand-written list of two roots.

## Non-goals
- No file other than `z-nile/tests/acceptance/c0043/rounds.spec.luau` changes.
- The `./zn metrics` crash on `idea` and `idea-challenge` spend rows is not fixed here; it stays with d0406.

## Solution
- The case builds its expected list from every registered project's root (`rafts`, `rafts/active`, `rafts/done`, `rafts/retired`), so with d0406 fixed it passes on main and keeps passing when a project root or a raft is added.
- The case still fails when metrics leaves a raft out, lists one twice or lists them out of order.
- With d0406 fixed and this change in place, `z-nile/tests/acceptance/c0116/retired.spec.luau` passes without being edited.
