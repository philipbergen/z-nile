# c0433: Work profile from env

## Problem
- A person who wants a session to trade some checking for speed has no single setting for it: each relaxation (review rounds, skipping the raft step, who merges, which gate runs when, whether guesses may reach main) must be agreed in chat and re-stated to every agent.
- No provenance row, spend row, review file or pull request body a session writes records which relaxations it ran under, so results from a relaxed session cannot be told apart from results of a full one.

## Non-goals
- A session started with the variable unset behaves exactly as it does today, and writes no profile name on any of the four writes.
- The board shows no profile: its content is the same whichever profile, or none, any session runs under.
- Commit messages and harvest lines do not carry the profile name.
- No profile can switch off the guards that keep specs and checks from changing the real repository.
- No profile lets an agent record an approval in the person's name.
- No settings file, command flag or mid-session command chooses or changes the profile in force.

## Solution
- The person sets one environment variable to a profile's name before starting an AI CLI, and every `zn` command and skill in that session follows that profile; the environment variable is the only way to choose a profile.
- A profile is a named entry in one tracked, editable file that sets exactly these choices: the number of review rounds, whether a raft is needed, who may merge and when, which gate runs when, and whether unapproved guesses may reach main.
- A variable that names a profile not in that file makes every `zn` command stop with an error that lists the known profiles.
- The worker prints the name of the profile in force as a line of its start-up output.
- The session writes the name of the profile in force on each of these four writes: every provenance row it adds to a ticket, every spend row, every review file, and the body of every pull request it opens.
- The cost and rework reports count rows that carry a profile name separately from rows that carry none.
