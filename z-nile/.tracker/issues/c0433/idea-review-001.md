# Idea review 001

## Findings

- F1: The first Solution sentence offers two ways to choose a profile: an environment variable, or "naming a profile in the settings". It doesn't say which settings file it means, or which one wins when the two name different profiles, so a reader can't check whether the sentence holds. It also isn't the smallest fix. The Problem asks for one setting per session, and the environment variable alone provides that. A profile named in a settings file would apply to every later session too, so it is no longer per session. It also blurs the non-goal about sessions "when no profile is named".
