# Idea review 001

## Findings

- F1: Under the current rules, the slim path would never be used. The idea picks the design path by whether a ticket is marked easy, but a ticket only gets that mark (`risk: easy`) once its draft is finished (`z-nile/skills/z-design/SKILL.md:59`). When a design starts, no ticket is marked easy, so every ticket would still get the full design and the 195,000-token cost stays. The non-goal "does not decide how a ticket comes to be marked easy" rules out the one change that would make the path reachable. It needs to be a solution sentence instead, such as "the mark is set before design starts", or the idea has to name who sets the mark before design.
