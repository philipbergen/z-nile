# c0436: One set of stage names

## Problem
- A ticket's place is told today in several vocabularies at once (the status values and folder names new, preparing, prepared, active and done, the idea states unchallenged and challenged, the design states draft, reviewed and ready, the skill names, and the board's column names), so a person has to translate between them.
- No single word today tells apart an item that left the flow without landing (an issue closed as won't do by `./zn close`, a raft under `rafts/retired`) from one that is still in the flow.

## Non-goals
- This ticket does not rename the stored status values or the folders (`active/`, `done/`, `rafts/retired/`); they are only shown under the new words, and renaming them would be a separate ticket.
- The steps a ticket goes through, and what each step requires, do not change; only the words for them do.
- The skill and command names (z-ticket, z-design, z-raft, z-ready, z-work) are not renamed by this ticket.

## Solution
- Everywhere a person reads or types the stage of an item that is in the flow (the commands' output and arguments, the board and the app, the skills, the README, the live layer's events and the stats), the stage is one of idea, design, code, review, approval or landed, and no other word names any of those six stages.
- The one exception, in every one of those places, is a literal file path or a literal stored `status:` value: a command's output, the board, the app, a skill, the README, a live event or the stats may still print one (such as the `…/rafts/active/<R-id>/prompt.md` that `./zn prompt <R-id> --path` prints, or `…/done/<ID>`) to say where a file is or what a file holds, and never to say which stage an item is at.
- The skills and the README each state once which stage every folder name and stored `status:` value stands for.
- An item that left the flow without landing (an issue whose stored status is the `closed-…` stamp `./zn close` writes, a raft under `rafts/retired`) is shown in all those places with the one terminal word closed, never at any of the six stages.
- Every existing ticket and raft, written before the change, is shown at exactly one of the seven words (the six stages or closed), with no edit made to its file by hand.
