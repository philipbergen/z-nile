# c0441: Split main luau

## Problem
- One more non-constant top-level local in `z-nile/engine/main.luau` (9,195 lines) makes `lune run` fail with "Out of local registers ... exceeded limit 200", and `./zn --help` then fails to start.
- 19 `require` calls in `main.luau` sit inside functions instead of at the top of the file, because a top-level local could not be added.
- Two zz-arch lessons, `main-luau-local-limit` and `engine-main-local-limit`, tell every design and build that `main.luau` is at Luau's limit of 200 locals and must not gain a top-level local.
- Comments at `z-nile/engine/main.luau:6174`, `z-nile/engine/main.luau:7894` and `z-nile/engine/liveemit.luau:11` give the same warning as the reason a `require` sits inside a function.
- No check measures how close an engine file is to the register limit, so the first sign of passing it is every `./zn` command failing to start.

## Non-goals
- No command gains, loses or renames an argument or an output line.
- No engine file other than `main.luau` is split; the next largest, `dispatcher.luau`, has 80 lines that start with `local` and already passes the check.
- The check does not parse Luau scopes or count registers; it counts lines that start with `local`, a rough stand-in set well below the limit of 200 registers.
- No new lesson replaces the two retired ones; the gate check is what warns a build that a file is near the limit.

## Solution
- Each command's code lives in a module of its own under `z-nile/engine/`, and `main.luau` only parses the command line and calls those modules.
- `main.luau` has at most 100 lines that start with `local`.
- Every `require` in `main.luau` is at the top of the file, none inside a function.
- Every command prints the same output and exits with the same code as before the split, for the same arguments.
- A check in the gate fails when any file in `z-nile/engine/` has more than 150 lines that start with `local`, and names the file and its count.
- The lessons `zz-arch/main-luau-local-limit` and `zz-arch/engine-main-local-limit` are retired, and `./zn lessons main.luau local` returns neither.
- No comment in `z-nile/engine/` says that `main.luau` is at the limit of 200 locals or has no room for another top-level local.

- idea-review-001 F2: The solution is bigger than the problem needs. Giving every command its own module and cutting the main file down to command-line parsing is a full rewrite of 9,195 lines. The problems listed (the 203 lines starting with `local` in `z-nile/engine/main.luau`, modules required inside functions, the warning in every build brief) are all solved by moving enough code out to bring the count down, plus the check. Nothing in the Problem section calls for the full per-command split. Answer: disputed: the per-command split is what the rough idea itself asks for ("each command's code lives in a module of its own and the file that remains only parses the command line"), so cutting it to "move enough code out" narrows the captured scope, which only the owner can rule on.
