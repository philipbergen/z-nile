# c0449: Fixture cost remainder

## Problem
What c0178 ("Shared fixture images") no longer delivers. c0178 was cut to slice 1 (`trackerfix.new` clones a per-run packed template) by design review 005 and the owner's ruling. The owner (2026-11-24), on c0178's code review 001 F2: "b and log a feature for the rest of the work if neded". Option (b): slice 1 merges now as progress, and this ticket holds the rest. The earlier decisions it carries:
- The user (2026-10-31): "This is not acceptable. Find a better solution. Test has to be thorough and complete but also very fast and efficient." Decided with the user (2026-10-31): fewer files **and** a fixture volume fseventsd ignores.
- c0178's capture (2026-10-31): "build packed images once and clone them, to cut file churn and processes".
- Scope decision (user, 2026-11-01), c0178: "Fix in c0178" for the working tree the eight repository-cloning specs check out: `--no-checkout` plus the paths each of those specs reads.
- Scope decision (user, 2026-11-01), c0178: "Convert them" for the 11 hand-built four-repository fixtures: move them onto `trackerfix.new`, with their overrides.
- The owner approved c0178's earlier design on 2026-11-19 (`z-nile/.tracker/issues/c0178/approval.md`). That approval included outcomes the redesign dropped.

Measured in c0178 (2026-11-24): a fixture starts 88 processes today and about 76 with slice 1. After slice 1 removal is about half of a heavy spec file's remaining events (37% to 54%). A per-run RAM disk that is detached rather than emptied took light-path from 51,305 to 23,744 events (c0178 E7).

## Non-goals
- Slice 1 itself (c0178).

Proposed risk (for the prep to set): `risky`, because it changes the fixture helpers most specs use and, with the volume, the runner's lock, jail and reaper. `./zn land` refuses a `risk:` line or a `guesses.md` in a capture.

## Solution
Each outcome is one statement a later claim can find true or false:
- The ten hand-built four-repository fixtures (`c0067/ready`, `c0068/stop`, `c0069/prompt`, `c0070/board-refresh`, `c0072/land`, `c0081/allocate`, `c0081/compact`, `c0081/remap`, `c0084/spend-command`, `tooling/remap-once`) build their fixtures with `trackerfix.new`, with every case and assertion kept ("Convert them").
- The repository-cloning specs (`clone.isolated` of the checkout) write fewer files than a full checkout each ("Fix in c0178"); whether by `--no-checkout` plus paths or a cloned checkout template is the design's, put to the owner.
- One `trackerfix.new` starts measurably fewer processes than the 88 of today: one `fixture.check` per `fixture.git` call, or another mechanism ("and processes").
- On macOS a gate-driven run keeps its fixtures on a per-run volume that it detaches instead of emptying. Its design must first answer c0178's design review 005 F14 to F19: the lock across the mount, a runner flag no nested run inherits, R0070/c0194's run folder under the mount point, a lifeline and `./zn reap` for a killed run's volume, the module's home in `z-nile/lib/`, and time limits with safe carry-out.
- A fixture repository holds no git sample hooks (an empty `init.templateDir` for fixture git).
- The gate prints `fixtures: N files written, M processes started` beside `slowest:`.
- `c0116/claims` makes its twenty worktrees from one.
- A passing spec's fixtures are removed, or the reason not to is recorded with the numbers (c0179 E8: removal is half of all events).
- `fxclone.tree` and the template path are checked on a Linux host: one `cp -a --reflink=auto` per fixture there, with the entries per fixture counted.
- c0178's case "a rewrite to a wrong path refuses before any push" uses a live repository at the wrong path and compares its tip (c0178 code review 001 F8 b).
- A templates folder that is a link is refused by a case that can make one (c0178 code review 001 F8 d; the macOS jail refuses such a link, so the case needs another host or a seam).
