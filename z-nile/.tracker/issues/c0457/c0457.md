# c0457: Single source skill boilerplate

## Problem
- Identical `## Lessons` paragraphs across all 19+ registered skills in `z-nile/skills/` and `<project>/skills/` and duplicated `## Headless` paragraphs in `z-idea`, `z-design`, `z-raft`, and `z-code` force multi-file lockstep edits (`z-design/restated-rules-move-together`, 410 citations) and bloat every skill read.
- Promoted specs `c0111/skill-docs.spec.luau` and `c0117/docs.spec.luau` currently pin byte-for-byte copies of those duplicated blocks across every skill.

## Non-goals
- Trimming the main procedural bodies of the pipeline skills, which belongs to `c0467` after Waves 2-3 land.
- Changing headless dispatcher runtime behavior or lesson file frontmatter rules.

## Solution
- Keep the authoritative `Headless` and `Lessons` rules once in `z-nile/skills/zz-rules/SKILL.md` and replace the duplicated `## Headless` and `## Lessons` sections across all non-alias skills in `z-nile/skills/` and `<project>/skills/` with concise one-line pointers checked by `./zn skills --check`.
- Narrow `z-nile/tests/acceptance/c0111/skill-docs.spec.luau` and `z-nile/tests/acceptance/c0117/docs.spec.luau` via explicit `Overrides:` (`pin.digest`) to assert the single-source pointer contract, and graduate `z-design/restated-rules-move-together` into `z-nile/skills/graduated.tsv`.
