# c0466: Automate spend and preflight hooks

## Problem
- Agents still spend prompt instructions and manual tool turns invoking `./zn spend --begin` / `./zn spend` across prep, review, and capture stages and manually running static + guard preflight checks before `./zn finish` (`zz-execute/a-builder-runs-every-static-step-and-guard-before-reporting`).

## Non-goals
- Removing explicit `./zn spend` or `./zn check` CLI commands for callers and promoted specs that invoke them directly.

## Solution
- Fold automatic session spend measurement (`claude`, `grok`, `kimi`, and `f0459`'s `agy` `transcript.jsonl`) directly into `./zn status <id> preparing`/`prepared`, `./zn finish`, `./zn done`, `./zn dispatch zz-review`, and `./zn land` (idempotent when a manual row was already recorded).
- Run static and guard preflight stages automatically inside `./zn finish` before final spec execution and graduate `zz-execute/a-builder-runs-every-static-step-and-guard-before-reporting` into `z-nile/skills/graduated.tsv`.
