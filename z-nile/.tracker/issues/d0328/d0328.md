# d0328: Spend session cwd slash

## Problem
./zn spend hands process.cwd to sessionread.span unstripped. Lune's process.cwd ends in '/', so the Claude project folder span looks under (~/.claude/projects/<the cwd with each / as ->) ends in '-' and no session is found; sessionread.running strips the slash, span and its caller do not. So a spend row never carries a Claude session's measured model, tokens or AI time: every row c0250's prep recorded with ./zn spend on 2026-11-14 (design-review-001, design-refute-001, prep) has none and says 'unmeasured tokens,ai'. Found by c0306's prep (2026-11-14); the probe was not run against main. What should happen: the cwd is stripped of its trailing / once, where span builds the folder name, and a spec seeds a session under the real folder name only and pins that spend measures it. Not in scope: re-measuring rows already recorded, and c0306's rule that a typed --model wins over the measured model.
