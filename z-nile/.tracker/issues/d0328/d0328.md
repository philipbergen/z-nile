# d0328: Spend finds no Claude session

## Problem
- `./zn spend` run from the repository root or from any `.worktree/<name>/` records `unmeasured tokens,ai` even when a Claude session exists for that directory, because `sessionread.span` builds the project folder name from a cwd that ends in `/` and replaces only `/`, while Claude Code's folder name has no trailing `-` and has `-` for each `.` as well (`…-pickman--worktree-<name>`).

## Non-goals
- Rows already recorded are not re-measured, c0306's rule that a typed `--model` wins over the measured model is unchanged, and no character other than `/` and `.` is mapped.

## Solution
- `sessionread.span` strips the cwd's trailing `/` once and maps both `/` and `.` to `-` when it builds the folder name, and a spec seeds a session only under the real folder name of a `.worktree/<name>/` cwd ending in `/` and pins that spend measures its model, tokens and AI time.

## Design
The fix is inside `sessionread.span`, the adapter that reads `$HOME/.claude/projects/<folder>`. No new module, no new type, no change to any signature.

- **Rule**: the key is the cwd with one trailing `/` removed, then every `/` or `.` replaced by `-`. Written as `local claudeKey = string.gsub(string.gsub(cwd, "/$", ""), "[/.]", "-")`, and `claudeDir` is `{h}/.claude/projects/{claudeKey}`. The rest of `span` (the `filesUnder` walk, `sessions.claude`, the grok branch) is unchanged.
- **Not reused**: `sessionread.claudeDirs` already names a strict spelling, but its pattern `[^%w%-]` maps every other character too, so `_` would become `-`. Non-goals forbid that, so `span` keeps its own `/` and `.` rule.
- **Root cause**: `span` maps only `/` and keeps the trailing `/` as a trailing `-`. No spec caught it because the only `span` case uses the cwd `anywhere`, and `claudeDirs` (`work.spec.luau`) pins folder names without calling `span`.
- **Siblings**: the same trailing-`/` and `.` mistake sits in four other readers, none fixed here, because the Problem names the Claude folder of `span` only; all four are put to the user under Open to the human (design-review-001 F2, design-review-002 F1). `sessionread.running` (the `finish` and `done` spend rows) maps only `/`. The grok folder (`sessionread.encode`, called by `span` with the cwd still ending in `/`, so `%2Fa%2Fb%2F`) and the cursor folder (`cursorKey`, `a-b-`) keep the trailing `/` and match no folder on this machine. `claudeDirs` keeps its own mapping.
- **Pure/adapter split**: unchanged. `span` is already an adapter (it reads files and `HOME`). Server authority: not applicable (tooling).
- **Scalability / Maintainability / Usability**: one `gsub` pair on a path of a few dozen characters, once per `./zn spend`. The rule stays in one line beside its comment, so a later change to Claude Code's naming is one edit. The user sees the same output as before, except that a `.worktree` checkout now reports its measured model, tokens and AI time instead of `unmeasured`.

## Open to the human
- design-review-001 F1: the Non-goal "no character other than `/` and `.` is mapped" leaves `./zn spend` unable to measure a checkout whose path holds `_`, a space or another character, because Claude Code maps every character outside letters, digits and `-` to `-` (the folder names in `~/.claude/projects` show it, and `sessionread.claudeDirs` says the same). The capture (commit 3cadd2cef) asked for the session "under the real folder name"; the Solution's "maps both `/` and `.`" and that Non-goal came from the idea step (commit 3290615a3, answering idea-review-001 F1, which asked only for `.`), with no ruling by the human. Answer: the design keeps the rule as the idea step wrote it and pins no `_` case. Decision: keep the rule as captured (checkouts with such characters stay unmeasured, a known gap), or widen it to every character outside `[%w%-]`, which drops the Non-goal clause, adds a spec that pins `_` to `-`, and makes `span` strip the trailing `/` before it maps.
- design-review-001 F2, design-review-002 F1: four readers of the same cwd make the trailing-`/` or `.` mistake and are not fixed here, because the Problem names the Claude folder of `span` only: `sessionread.running` (`z-nile/engine/sessionread.luau`, the `finish` and `done` spend rows) maps only `/`; the grok folder (`sessionread.encode`, which `span` calls with the cwd still ending in `/`, so `%2Fa%2Fb%2F`) and the cursor folder (`cursorKey`, `a-b-`) keep that `/`, and no folder on this machine matches either. Answer: not fixed here. Decision: either fix them all in d0328 (strip once at the top of `span` for grok and cursor, a case and a row each; and `running` through the one key function `span` uses, since `running` reads `process.cwd`, which a spec cannot set, so the Design's "no change to any signature" needs a shared function; say whether `running` keeps the loose spelling as a fallback), or capture one defect for all four and name its id in Siblings. Cursor's own treatment of `.` is not pinned by any case until its real folders are checked.
