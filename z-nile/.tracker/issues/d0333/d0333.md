# d0333: Commit after finish unfinishes the layer

## Problem
c0306's prototype (2026-11-14) reported that ./zn commit after ./zn finish rewrites the raft folder's spend.md, which layergit.isPostFinishPath does not list: it allows only the raft folder's review-, refute-, final-review- and final-refute- files, trace.md, the raft document and spend.d/. So the finished layer reads as not finished. Yet zz-execute Phase 5 says to commit trace.md and the final review files with ./zn commit --phase code-review. The prototype's done fixture had to run ./zn finish again after that commit. It has not been reproduced on main. What should happen: reproduce it with a raft that finishes its last layer and then commits its final review with ./zn commit; then either the post-finish rule takes the raft's spend.md, or commit no longer rewrites it after finish.
