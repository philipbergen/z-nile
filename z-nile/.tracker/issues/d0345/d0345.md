# d0345: Work next stuck on deferred review

## Problem
./zn work next reads only the newest code review's verdict (workread.reviewState): a review whose verdict is changes stays open for ever, although its refute answers every finding fixed, refuted or deferred and ./zn done accepts it (main.luau reviewProblem). There is one review round and a review file is never edited, so the line 'Answer the open code review until its verdict is approve' can never change, and the worker cannot reach the trace and final-review lines. R0102 (2026-11-14): review-001 had one medium finding deferred to c0341; the executor left ./zn work next and followed zz-execute Phase 5 by hand. The final review has the same reading. Wanted: ./zn work next treats a review as resolved by the same rule ./zn done uses.
