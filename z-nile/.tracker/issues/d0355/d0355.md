# d0355: Dispatch env reaches fixture specs

## Problem
Under ./zn dispatch a spec's fixture inherits the dispatcher's ZN_PUBLISH_BROKER/ZN_PUBLISH_TOKEN and its git wrapper first on PATH (z-nile/bin/git): ./zn ready inside a fixture dies in broker.request, and a fixture's own push of a non-tracker file to its own main is refused as 'not tracker state'. Seen in c0300's prep (2026-11-15): tests/tooling/stack-land.spec.luau fails its setup case in a dispatched session and passes with those variables unset and z-nile/bin off PATH (c0300 experiments/plainenv.sh). A dispatched executor or gate run cannot run fixture specs that ready, start or push.
