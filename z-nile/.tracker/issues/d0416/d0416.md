# d0416: Quiet nested review reported failed

## Problem
- Since commit 2c6197382 (d0415, R0136), `tests/acceptance/c0117/control-cli.spec.luau` :: 'an author waiting on a long nested review stays alive by its heartbeat; a quiet one still stalls' fails at line 421 in the slow tier because a nested review that goes quiet during a dispatched design step is recorded with outcome failed, where it is stalled on the parent c93b49aea.

## Non-goals
- This fix does not make the other red slow-tier cases pass (`c0116/compact-record`, `c0116/claims` and `c0114/trail-move`, which d0298 owns, and `c0045/workstreams` and `c0114/classified`, which go to c0304 and c0266), and it does not make the spec's waits independent of machine load (c0287).

## Solution
- A nested reviewer that goes quiet is stopped at its own limits and its run state says stalled, so that c0117 case passes in the slow tier, every d0415 acceptance spec still passes (a refolded raft's review is kept and not refused), and the change turns no other slow-tier case red.
