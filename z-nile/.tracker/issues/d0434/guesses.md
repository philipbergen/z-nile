Example: layers 1, 2 and 3 all move and layer 3 conflicts; layers 1 and 2 are already pushed when it stops. Why: a conflict resolution changes the patch id of every commit it touches, so patch ids would call the worker's own resolved commit foreign; a subject kept by the rebase is stable. A commit whose subject was reworded by hand counts as foreign and stops the run with a message.
