# c0039: Duplicate id detection

## Problem
Two PRs can pick the same tracker ID (it happened with c0034, PR #2). Git merges different files inside a same-named directory cleanly, or the ID collides only in a way `store.find` silently resolves, so a duplicate can reach `main` unnoticed. With agents merging on their own (c0037), nothing catches it. Add a check in `scripts/check.sh` (or `tracker.sh done`) that fails when the same ID exists in more than one lifecycle directory.
