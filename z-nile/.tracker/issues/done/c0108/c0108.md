# c0108: Quoted board download

## Problem
`tracker.sh done R0038` promotes c0107's `keep.spec.luau` into `tests/`. That spec quotes `rm -rf .cache/board-ci`, and `tests/acceptance/c0048/board-docs.spec.luau` quotes the same path. c0049 treats a literal `.cache/<dir>` as a fixture, so the done-tree gate fails: `board-ci used by board-docs.spec.luau, keep.spec.luau`. Neither spec writes that directory. It blocks `done`, so it cannot be postponed.

## Non-goals
- Editing c0107's sequestered `keep.spec.luau`.
- Exempting `board-ci` in the scanner. A spec that really uses that directory must still collide.

## Solution
Build c0048's two download tokens by concatenation, the way c0049 builds its own pattern, so the assertions stay and the source no longer contains `.cache/board-ci`. After promotion, only `keep.spec` names it.

## Design
`tests/acceptance/c0048/board-docs.spec.luau` builds `".cache/" .. "board-ci"` and concatenates that into `rm -rf ` and `-D `. The skill row is unchanged.
