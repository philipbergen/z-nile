### F1 [low] The carried diff's upper end is a branch name while its path list is frozen at what 97c35b43 changes, so a later commit on impl-c0118 that touches a 16th path is dropped silently
Where: step 1, **Apply** (`git diff 434d94e1 impl-c0118 -- <15 paths>`; "`impl-c0118` (#122) is reference only")
Evidence: the 15 paths are exactly what `434d94e1..97c35b43` changes outside the tracker, `next` and lessons (count above). impl-c0118 has moved often (its last commit, 97c35b43, carried rounds 006 to 009 and a zz-rules row rewording), and nothing in step 1 says it is frozen or checks its tip. Critique: the lower end got pinned (review 010 F3) but the upper one didn't, and the path list depends on both. The tempting fix is "carry `.` minus `next` and lessons". That reopens review 010 F2 for whatever else main writes (the `.tracker` exclusion already exists; other main-written files may come).

Recommendation: write the upper end as the sha, `git diff 434d94e1 97c35b43 -- <15 paths>`, and add one check before it: `git diff --name-only 434d94e1 impl-c0118 -- . ':!*/.tracker/**' ':!z-nile/next' ':!*/lessons/**'` must list exactly the 15 (equivalently, `git rev-parse impl-c0118` = 97c35b43), else stop and escalate.
