### F1 [high] The home rule runs through the runner it is supposed to judge: a home whose `tests/run.luau` runs nothing passes its own gate, z-nile's gate and check.sh

- `cd snake && lune run tests/run -- tests/meta/home.spec.luau` printed nothing (`exit=0`), and `lune run tests/run` (the whole suite, what the gate's `tests (full): snake` stage runs) also exited 0.
- `cd z-nile && lune run tests/run -- .tracker/issues/c0184/acceptance/homes.spec.luau tests/acceptance/c0120/layout.spec.luau` gave `11 passed, 0 failed`.

Recommendation: add a case to homes.spec (promoted, z-nile's, run by check.sh AC1): "AC1: every registered project but z-nile passes the home rule, judged from z-nile". It runs `home.problems(TOP, projects.load(TOP))` and expects no problems and `checked` equal to every registered name but z-nile (pickman included).
