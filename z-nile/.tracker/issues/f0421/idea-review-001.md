# Idea review 001

## Findings

- F1: Two Solution sentences contradict each other. The seed says "an easy ticket uses a cheap model for design, design review, code and code review", which reads as one model for all four. But the idea also says "A reviewer is never the model that wrote the text it reviews". So either the seeded easy level breaks that rule, or the rule turns the seed down. The idea says neither which happens nor what happens whenever the configuration gives a writer and its reviewer the same model: is it refused when the configuration is read, refused when the review starts, or quietly replaced with another model? Until it does, a reader can't tell whether the easy seed is valid.

## Verdict

revise
