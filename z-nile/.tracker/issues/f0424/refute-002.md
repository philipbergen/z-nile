# f0424 code review 002: fixes

- F13: fixed: on a refused connection the client tries a non-blocking shared flock on `<state>/lock`, gives up at once when it gets it (no daemon holds it) and keeps retrying inside its 2 s budget when it would block (`TestKilledDaemonRefusedAtOnce`: `status` 3.1 ms and `claims` 2.9 ms against a `kill -9`-ed daemon; `TestDialUsesTheLockToTellDeadFromStarting` for a daemon that holds the lock but is not listening yet); consequences: `wire.Dial` takes the lock path (an empty path keeps the plain retry).
- F9: fixed: `TestIdleExitWaitsForFollowReader` decides liveness with `status` (exit 0 versus 3) instead of `kill(pid, 0)` on the unreaped child, and with `srv.Open() > 0` dropped from `serve.go` it fails ("the daemon idle-exited under a connected reader") and passes again once restored; consequences: no other process test used a signal-0 check on a daemon it started (the rig's cleanup kills and waits first), so none changed.
- N1: fixed: each worker records the seq of the event that created it (`registered_seq`), and a wait counts a removal as its own worker's end only when that event is after the registration the wait started under (`TestWaitSinceBeforeReregistrationNotGone`, and `TestWaitSinceBeforeReregistration` through the binary); consequences: snapshots carry one more field per worker.
- N2: fixed: the AC24 case in `live-gate.spec.luau` returns without asserting when there is no Go (the F10 cases cover that gate); consequences: none.
- N3: fixed: `_` was already in the id class (`[A-Za-z0-9._@:/-]`), so no pattern change was needed, and `TestUnderscoreAndOddHostNames` now pins it; the host part of a built worker id maps any character outside the class to `-` (a space, an apostrophe or a non-ASCII letter); consequences: the events' `host` field still carries the real host name.
