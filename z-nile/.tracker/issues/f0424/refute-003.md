# f0424 code review 003: fixes

- F1: fixed: the daemon starts from `/`, keeps its socket in the user's temp folder (macOS `getconf DARWIN_USER_TEMP_DIR`, elsewhere `/tmp/zl-<uid>/`) for the default state directory and in the client's TMPDIR for a named one, exits when its socket file or state directory is gone, and runs with an allowlisted environment (`TestDaemonOutlivesItsStartersFolders`, `TestDaemonExitsWhenUnreachable`, `TestStableSocketDirIgnoresTMPDIR`, seen failing on step 2's code first); consequences: the client passes `--sock-dir`, `ZN_LIVE_SOCKDIR` is the test-only switch, and `ZN_LIVE_LOST_AFTER` and `ZN_LIVE_IDLE_EXIT` no longer reach an auto-started daemon.
- F2: fixed: start times compare as epoch seconds within a second across `sec.usec` and `lstart`, and an unreadable record is refreshed, never reuse (`TestStartSpellingsCompareAsTimes` failed first; `TestKernelAndPsReadersAgree`); consequences: step 1 logs keep their workers.
- F3: fixed: a failed `--auto` rebuild writes `<bin>.failed`, is not retried for the same source id and prints one line per op (live-autostart.spec "a failed rebuild is tried once per source change"); consequences: `gobuild.sh` takes `--auto` and exits 4 for a recorded failure; `./zn live build` always tries.
- F4: fixed: a client whose `serve` exited while the lock is held waits up to 10 s for a free lock and starts once more (`TestWriteRightAfterShutdown`, 50 iterations, failed first); consequences: the start lock is gone, the instance lock is the one guarantee.
- F5: fixed: a relative `gitdir:` resolves against the worktree's top (live-cli.spec F5, from `/` and from inside); consequences: none.
- F6: fixed: the timing flags are forwarded only for a named state directory and refused with `usage` for the default one (`TestTimingFlagsRefusedForTheDefaultDirectory`, failed first); consequences: the spec helper passes them only when `ZN_LIVE_DIR` is set.
- F7: fixed: livecall answers 3 for an exit outside {0, 1, 2, 3, 75}, writes stdout to a file so a descendant cannot block past the timeout, rounds numbers, and ignores non-event fields, returning their names (livecall.spec, three cases); consequences: `livecall.emit` returns `(code, ignored)`.
- F8: fixed: `./zn live` run from outside every repository exports `ZN_LIVE_DIR=<main>/.cache/live` (live-cli.spec F8); consequences: `ZN_LIVE_DIR_IS_DEFAULT=1` marks that directory as the default one.
- F9: fixed: live-gate.spec F9 fails naming any non-test Go source or `go.mod` that a live spec's watch file lacks (it caught `start.go` at once); consequences: the watch files list the new sources.
- F10: fixed: livecall.spec cases for a non-executable and a directory `ZN_LIVE_BIN`, live-autostart.spec `out=$(./zn live register ...)` under 2 s, and the daemon's environment names asserted in the bounded-runner case; the start lock is removed (the instance lock is simpler and enough); consequences: none.
- F11: fixed: a lost worker holding no claim is removed after 24 hours with a reason, one holding a claim is kept (`TestLostWorkerWithoutClaimIsRemovedAfterADay`, failed first); consequences: an idle daemon can idle out.
