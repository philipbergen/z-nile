# f0450: Close work already on main

## Problem
There is no way to close a ticket whose code is already on main: sixteen hand-built z-nile tickets (f0420 to f0437, f0450, c0435, c0436, c0179, c0178, d0434, d0426) cannot reach done with a trace that cites their merged code.

Decided with the user (2026-11-24): "a". Asked whether c0435 and f0425, built by hand straight onto main, should (a) be closed now by reviews that judge the merged commits by reading them, the trace's code column `none` and each review's record naming the commits and pull requests it read, or (b) be closed only after a closing route whose trace cites named commits is built; this ticket stays the later improvement.
