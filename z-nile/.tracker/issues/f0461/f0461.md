# f0461: Check design linter

## Problem
- Mechanical design-contract mistakes—mismatched `ACn` bullets vs `check "ACn:"` lines (`z-design/spec-design-correspondence`, 431 citations), missing `Test plan` `spec :: case` entries in `acceptance/`, missing `Overrides:` lines, and unbounded experiment commands—are caught repeatedly by LLM review rounds instead of a fast deterministic CLI check.

## Non-goals
- Re-introducing pre-code `Rules and mutants` requirements that `c0460` moved to `zz-execute`.
- Static `check.sh` path and sequestration linting, which belongs to `c0463`.

## Solution
- Add `./zn check-design <id>` in a pure `z-nile/engine/checkdesign.luau` module and invoke it automatically inside `./zn status <id> prepared` to enforce 1:1 Checked `ACn` <-> `check "ACn:"` correspondence, behavioral `Test plan` `spec :: case` existence in `acceptance/`, valid `Overrides:` declarations, and `./zn run --time` bounded experiment citations.
- Graduate `z-design/spec-design-correspondence` and `z-design/experiments-record-their-bounded-command` into `z-nile/skills/graduated.tsv`.
