# R0070: Temp trees fixture identity

## Theme
Two members, both chores in z-nile, both about where git state and scratch clones may live, and both edit the same tooling and the same skill sentences.
- **c0194** (Temp trees under repo, size 850): every temporary tree the tooling, the gate or an agent makes lives under `<checkout>/.cache/.tmp/`, never `$TMPDIR`. One maker (`z-nile/lib/tmp.luau`, `./zn tmp new|jail|verify|rm|sweep|leftovers`), a `SessionStart` hook that sets every session's `TMPDIR`, the runner's per-run folder inside it, and the merge gate's clone made isolated by `./zn tmp verify`.
- **c0189** (Real repository refuses fixture identity commits, size 470): a `reference-transaction` hook in the real repository's shared hooks folder refuses any ref update to a commit authored or committed under `@example.invalid`, so a prototype branch cannot trip every running gate; `./zn hooks [--check]` installs and checks it, from `origin/main`'s copy; a gate stage, `setup.sh` and the merge's clone run it; the prototype rule ("a scratch clone under `.cache/.tmp/`, never a `git worktree add`, or your own identity") is stated in the skills.
