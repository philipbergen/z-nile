# R0102: Clone fixtures name main

## Theme
c0302 (Layer branch breaks clone fixtures, size 14), alone. Seven promoted fixture specs clone the checkout, remove `origin` and run `./zn start`, so on a stack layer branch the clone has no main and they fail with 'no main branch'. Each gains `git({ "checkout", "-q", "-B", "main" })` after its origin removal.
