### F1 [medium] The sequestration check recorded after the re-prep can't see acceptance-spec edits: `'tracker/issues/active/*/acceptance'` matches no file
Where: `tracker/rafts/active/R0016/R0016.md` "Addressed during execution", last paragraph; `tracker/rafts/active/R0016/design-refute-005.md` F2 (both rewritten in c108123 "scope the sequestration pathspec").
Evidence: git's wildcard pathspecs match the whole path, and unlike a literal directory pathspec they don't recurse. So `'tracker/issues/active/*/acceptance'` matches nothing below the directory:
- `git diff --name-status ca60ba2 5a369f0 -- 'tracker/issues/active/*/acceptance'` prints nothing. With `'tracker/issues/active/c0048/acceptance'` the same range prints `M …/c0048/acceptance/board-workflow.spec.luau`, which is the spec edit design-refute-005 made.
- `git diff --name-status c603241 HEAD -- 'tracker/issues/active/*/acceptance'` prints nothing. With `…/*/acceptance/*` it lists the modified `board-workflow.spec` and the deleted `setup-skip-gate.spec`.
The recorded check is therefore "empty" whatever happens to any member's acceptance spec. Only the `check.sh` half works. design-review-005 F2 recommended `'…/acceptance/**'`. accade2 used plain member directories, which did work but also caught the .md documents. c108123 then dropped the `/**`. `tracker.sh done` doesn't enforce sequestration, so this recorded command is the only guard for the rest of the raft, and every later reviewer is told to run exactly it.
For today: with a pathspec that works, `git diff --name-status 5a369f0 HEAD -- 'tracker/issues/active/*/acceptance/**' 'tracker/issues/active/*/check.sh' tracker/rafts/active/R0016/check.sh` is empty. No spec has actually changed since the baseline, so nothing is gamed now.
Critique: the re-prep turned "diff against the start commit" into a hand-written command, and the command is blind exactly where sequestration matters most: the specs an executor would be tempted to loosen while answering a review. The fix the author will be tempted to make is to swap in another hand-typed glob without checking that it sees anything.
Consequences: in git pathspec globs, `*` also crosses `/`, so `'tracker/issues/active/*/acceptance/**'` (or `…/acceptance/*`) matches every file under each active member's `acceptance/`, at any depth. Only this raft's members are in `active/` on this branch: main's items never sit in `active/`, so a later merge of main doesn't add noise. The edit is to `R0016.md` and a refute file, so the sequestration rule doesn't apply to it. Rewriting `design-refute-005.md` after its round is a second, smaller problem: answers to a closed design round should stay as they were written. Put the correction in R0016.md, and note it in this round's refute rather than editing 005 again.
Recommendation: in R0016.md, change the pathspec to `'tracker/issues/active/*/acceptance/**'`. Add a positive control next to it so the next reader can see the pathspec works: `git diff --name-status ca60ba2 5a369f0 -- '<same pathspec>'` must list `board-workflow.spec.luau`. Record in refute-002 that the corrected command is empty at the new head. Leave design-refute-005 alone, or restore its original line and let R0016.md carry the correction.
